# 期望勝率在哪些情況下錯，與玩家何時該停

統計研究所學期報告。以 Lichess 的公開對局檢驗：配對系統依等級分算出的期望勝率，在哪些情況下系統性地錯；據此給出修正後的勝、和、負機率，並檢查「輸了今天就休息」這類民間停止規則有沒有用。

本文件只寫最終結論、用到的方法與不採用的理由。估計值（係數、p 值、區間）一律在 `outputs/` 由腳本重跑產生，不寫在文件裡。各主題的細節見 `docs/README.md` 的索引。

## 為什麼用 Lichess

電競的 MMR 與期望勝率不公開，無法從外部檢驗。Lichess 公開了等級分系統（Glicko-2）、配對程式碼與每局的對局前等級分。關鍵是 **2014 年的 arena 錦標賽是隨機配對**：對手的強弱與玩家當下的狀態無關，等於一個天然的隨機實驗。若配對依等級分，剛輸的人分數下降、對手隨之變弱，「狀態」與「對手」的效果就分不開。

## 資料

- Lichess 官方資料庫，2014 年全年與 2015 年 1 至 6 月的標準棋 rated 對局（`data/raw/lichess/`，不入版控，下載方式見 `docs/data/data-fetching.md`）
- 只用對局前的資訊：`WhiteElo`、`BlackElo`；`RatingDiff` 是結果的函數，不用
- 2015 年 1 月 1 日至 4 月 19 日的 arena 保留為前瞻驗證樣本，尚未使用
- 帳號名稱只作串接鍵，任何輸出都不呈現個別玩家

## 結論

### 期望勝率本身

- **Elo 形式的期望得分不校準**：系統性高估強方的優勢，老手也一樣；白方有固定優勢；和局機率隨等級上升
- **最好的基準**是讓分差斜率隨雙方等級分不確定性（rating deviation，RD）變化的有序 logistic。純 Elo 形式與 Glicko 公式都是它的特例，兩者都被概似比檢定拒絕；它在新手、老手的樣本外預測都最好。以下所有分析以它為「系統的期望」
- **新手期**以 RD ≥ 110 界定（Lichess 標示 provisional 的門檻），但偏差隨 RD 連續變化、在門檻處沒有斷點；新手對局留在樣本，由上述基準吸收

### 剛被分到強對手、剛輸之後

- **配對確為隨機**，但開賽第一批之後絕大多數批次只有兩人同時空閒、只能配成一局，能做重新配對檢定的只有兩局以上的批次
- **Blitz**：被隨機分到強對手後，下一局的表現低於期望，只延續一局。Bullet 沒有證據
- 固定下一局對手後的「直接效果」方向相同但不顯著，因此類推到排隊配對的電競時，只能說方向一致、未能確立
- **只在續下者上成立**：被分到強對手的人較少繼續下。考慮這個選擇後，效果的上下界包含 0，對「不論對手強弱都會續下的玩家」未能確立
- **剛贏之後普遍好於期望，剛輸之後只有 RD 最高的玩家差於期望**；下一局的殘差可由上一局等級分變動預測，方向是等級分調得不夠，不是降過頭。這和「輸了心態崩」（tilt）在本資料分不開

### 交付物

- **修正後的勝、和、負機率**：在基準上加入上一局結果（三種速度都保留）與上一局等級分變動（Blitz、Classical 保留）。改善在樣本外成立但幅度小；修正集中在剛贏之後
- **停止規則的建議：輸了不必停**。「一路下到第一次輸」與「連輸兩局才停」在回測中都沒有用，輸棋之後繼續下的局不比保留的局差；隔天第一局反而明顯低於期望，停下只是把局移到更差的位置

### 附錄的結論

- 隨機配對下，配對越懸殊，短時間內離開越少；這有一大部分是懸殊的對局下得較短，不可解讀為玩家偏好懸殊的配對
- 「給定本局結果，對手強弱不再影響離開」這個常見假設不成立（贏得越懸殊越少離開、爆冷輸後離開最多），所以推不出「等實力配對最好」
- 電競文獻常用的「觀察資料加玩家固定效應」做法，在自選對手的大廳對局上，控制自身等級分後效果變號，不可靠

## 方法：用到的基礎工具

各方法都以修課內容的組合描述。完整規格見 `docs/methods.md`。

| 問題 | 做法 |
|---|---|
| 勝、和、負的機率 | 有序 logistic（cumulative logit），和局不當成二元結果 |
| 期望得分準不準 | 以 logit(期望得分) 為解釋變數的 logistic 迴歸，看截距是否為 0、斜率是否為 1；校準曲線 |
| 三個基準比較 | 造一個包住其他兩者的大模型，改成巢狀的概似比檢定；另以時間切分的樣本外對數分數比較 |
| 同一玩家多局不獨立 | 概似比統計量照算；它漸近為常態向量的二次型，觀察值相依時共變異數改由資料估計（sandwich），分布變成特徵值加權的卡方和；以模擬核對檢定水準 |
| 剛被分到強對手的總效果 | 在同一配對批次內依原規則重新配對，以 Monte Carlo 求統計量的虛無分布；區間由反轉檢定求得 |
| 直接效果 | 每位玩家算「上一局對手偏強之後」減「偏弱之後」的平均殘差，對玩家做配對 $t$ 檢定 |
| 對照 | 每批一個截距的 logistic 迴歸中對處理項的 score 檢定；玩家 bootstrap |
| 輸棋本身的效果 | 兩段平均得分差相除，區間用 delta method |
| 續下的選擇 | 續下的 logistic 迴歸；續下率較高的那組依續下率之差，以樣本分位數修剪掉分布上端或下端，得兩組都會續下者效果的上下界；以續下機率倒數加權作對照，與重要抽樣的權重同理 |
| 等級分是否剛輸後失準 | 校準迴歸加入「上一局等級分變動」，以概似比檢定其係數 |
| 修正後的勝率 | 以基準為 offset 的有序 logistic，依序加入候選項，樣本外對數分數改善才保留；LightGBM、XGBoost、MLP 只作預測上限的參照 |
| 停止規則 | 回測：把規則套到實際序列，比較被刪去與保留的局的平均殘差；玩家 block bootstrap；多條規則以 Holm 法（逐步的 Bonferroni）校正 |
| 停止規則為何可能無效 | 期望勝率準確時等級分是 martingale，任何停止規則都不改變期望（optional stopping theorem） |
| 每局的 RD | 照 Lichess 原始碼逐局重放 Glicko-2：實力的常態先驗加一局結果的常態近似概似，事後平均即等級分、事後標準差即 RD；以表頭等級分校正 |
| 流失模型的對照 | 以玩家流失次數（截距的充分統計量）為條件的條件概似，消去玩家截距 |
| 連續對局的門檻 | 對數開局間隔的兩成分 Gaussian mixture，以 EM 擬合 |

共通原則：

- 檢定優先序為概似比 > score > Wald
- 樣本大，幾乎任何一項都顯著，所以效果一律換算成「相當於讓對手幾分」並附區間
- 方法的主從在看結果前寫定；同一環節的多個診斷以 Holm 法校正
- 能用基礎方法就不升級；機器學習只用於預測，不用於因果結論

## 試過但不採用的做法

| 做法 | 問題 | 改用 |
|---|---|---|
| Elo 公式的期望得分當真值 | 被概似比檢定拒絕，高估強方 | 加入 RD 的有序 logistic |
| 從 1500 起純重放 Glicko-2 | 資料始於 2013 年，之前的對局不在資料中，重放大多與表頭不符 | 每局以表頭等級分校正後重放 |
| 月檔的 `time_class` 分速度 | 2015 年 4 月下旬以前，部分有加秒的大廳對局被標到慢一級的類別 | 依重放判定的 `speed`；修正後結論不變 |
| 只用空閒超過 12 人的批次做隨機化推論 | 這種批幾乎只出現在開賽第一批，樣本不夠 | 兩局以上的批做 permutation test；一局一批另用模型分析、分開陳述 |
| 以時間窗內是否離開為續下的結果 | 效果大小隨時間窗變，且受對局長度的機械效果影響 | 「本場內是否再開一局」的二元結果 |
| 一般的卡方概似比檢定、sandwich Wald 檢定 | 相依資料下 p 值過小；Wald 在效果大時不穩 | 修正的概似比檢定（Bullet 的有效玩家數較少，接近邊緣的結果保留） |
| 有序 logistic 係數相除求「輸棋本身的效果」 | odds ratio 不可 collapse，相除沒有意義 | 平均得分差相除 |
| 假設續下與表現無關（倒數機率加權當主結論） | 被分到強對手的人較少續下，續下模型的檢定拒絕；tilt 本身就同時影響兩者 | 上下界為主，加權只作對照 |
| 不假設單調性的上下界 | 寬到沒有資訊 | 只作對照，顯示單調性收窄多少 |
| 用 RD 分層區分「等級分調得不夠」與 tilt | 大部分玩家的 RD 集中在下限附近，分層幾乎沒有差異 | 不再區分，寫成限制；交付物只需預測力 |
| arena 的整體校正項 | 樣本外不改善 | 不放入修正後的勝率 |
| LightGBM、XGBoost、MLP 當主模型 | 全體與老手組都不如有序 logistic，只在新手組較好 | 只作參照；新手組的差距登記為事後假設 |
| 固定效應 logit 估流失 | 每位玩家的觀察日數少，偏誤明顯；自選對手下控制自身等級分後效果變號 | 每組有自己截距的 logistic（條件概似的 logistic 迴歸）；結論為此做法在自選對手下不可靠 |
| 依連續對局最終長度分組比較各局表現 | 長度由各局結果決定，等於以未來的結果為條件 | 停止規則的回測 |
| AIC、BIC 選模型 | 相依資料下懲罰項沒有依據，差值沒有標準誤 | 概似比檢定、樣本外對數分數 |
| 線性機率模型 | 機率可超出 [0, 1] | logistic 類模型 |
| 有限混合迴歸、狀態空間模型、GRU | 前者每位玩家局數太少不可分辨；Glicko 本身就是狀態空間模型；GRU 的問題可由 LightGBM 加滯後項回答 | 依速度與新手分組；校準迴歸的殘差診斷；LightGBM |

範圍外、刻意不做的分析與理由見 `docs/plan.md`「不做的分析」。

## 限制

- 剛輸之後的偏差來自 tilt 還是等級分調得不夠，本資料分不開
- Blitz 的效果只在續下者上成立
- arena 的總效果含「上一局影響下一局對手」這條 arena 特有的管道
- 類推到電競：Lichess 是一對一、無隊友；2015 年 4 月 arena 改制只讓等級分輕微影響配對，且與同期其他改動混在一起，不可解讀為「依等級分配對」的效果
