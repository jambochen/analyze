# 研究設計

## 研究問題

**主問題**：以對局前等級分給出的期望得分為基準，玩家在一次連續對局中，第幾局之後表現開始低於期望？剛輸棋就立刻再開一局，表現是否更差？

**前置問題**：期望得分是否校準。依分差、等級、時間制與新手期分層檢查。期望得分若有系統偏差，表現殘差會混入基準的誤差，不能解讀為衰退。

**延伸問題**：配到等級分差距大的對手後，玩家是否較早離開。資料無法區分系統配對與指定邀戰，邀戰的雙方常是熟人，差距與離開的關係會被混淆，故只作延伸。

## 交付物

停止規則的建議：連敗幾局或連續下幾局之後，表現低於期望的程度足以建議休息。走「具體可行的建議」路線。

## 為什麼用期望得分當基準

等級分系統本身給出每一局的期望得分，基準不必另外估計。實際得分減期望得分即排除雙方實力後的表現，論證的負擔落在「基準是否校準」，而這一點可以直接檢驗。

## 主要的威脅

- **續下的選擇**：輸棋後是否繼續下取決於結果與狀態，局序越後的樣本越經過選擇。比較不同局序的平均殘差會混入選擇效果
- **等級分的機械更新**：輸棋後等級分下降，下一局的期望得分隨之調整。殘差以對局前等級分為基準，已扣除這個機械效果；但等級分更新本身有延遲，衰退的估計須考慮這一點
- **新手期**：新帳號的等級分不準，殘差反映的是基準誤差而非表現
- **時間制**：Bullet、Blitz、Classical 的對局長度不同，連續對局的切分門檻與疲勞機制可能不同，須分開處理

## 資料選擇

取 Lichess 官方資料庫 2014 年全年的標準棋 rated 對局。

- **為什麼用 Lichess**：唯一同時公開雙方帳號、對局前等級分與精確開始時間的大型對局資料，可串出每位玩家的連續對局。授權為 CC0
- **為什麼用 2014 年**：單月規模已足以切出大量連續對局，全年的壓縮檔可在本機處理。連續十二個月讓跨月的序列不在月底截斷。研究問題只用表頭，2014 年尚無時鐘與引擎評估標註不影響本題
- **只用表頭，不解析棋步**
