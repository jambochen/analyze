# 固定局前機率的序列參考診斷

問題是單局預測改善是否也伴隨較接近實際的連敗與累積得分偏差。借用 Gee 的模型模擬檢查與 Chowdhary 的連敗摘要，使用既有 Lichess Bullet、Blitz 的兩段時間外測試及 baseline、recent、novice_extension 固定係數，不重估、不選模。方法來源與遞迴模擬的差異見[文獻方法評讀](background/competitive-game-methods.md)。

## 樣本與計算

沿用自身在本場有上一局的玩家局。序列在玩家、錦標賽、測試期間與不連續局序處切開；只計算完全落在同一連續區段的滑動視窗，首局不補造、沒有後續對局的視窗不補值。和局得半分且中斷連敗。

事先指定的摘要為連輸 2、3、4、5 局的視窗比例，以及 5、10、20 局視窗的累積得分殘差平方，除以該視窗的獨立參考變異和。後者的獨立參考期望為一；偏大表示偏離逐局預期的累積程度較大，不分偏好或偏壞。連敗比例的解析參考是各視窗局前負率乘積的平均。重疊視窗照計，不視為獨立樣本。

每種摘要同時報視窗等權與玩家等權；玩家等權先平均每位玩家在該分組的有效視窗，再跨玩家平均。另依視窗第一局自身 RD 是否超過 110 分組；不是任一方新手，也不是事後平均能力。每列輸出有效視窗與玩家分母；沒有有效視窗的分組保留零分母與 NaN，不作結果解讀。

固定全部觀察到的局前特徵，獨立抽取每個實際對局的勝和負，並將同一結果反轉給對手視角。雙方皆在樣本時，須核對機率反轉一致。使用固定亂數種子及跨模型共用的均勻亂數，正式執行 200 次；報模擬平均、中央 95% 參考範圍及平均的 Monte Carlo 標準誤。解析期望另存，檢查模擬實作及精度。參考範圍不是參數信賴區間，也不輸出虛無檢定 p 值。

## 解讀界線與用途

未來的評分、近況、對手、局數及續下本身可能受先前結果影響。固定這些已觀察到的值再抽賽果，不構成原過程的生成虛無模型；尤其 recent 的歷史欄仍取自真實結果，不由模擬結果回填。因此偏離參考範圍不能作為拒絕獨立性、證明 tilt 或支持操控的檢定。模型係數不確定性也未納入。

這項探索只比較觀察型態與明確定義的人工參考，找出單局預測用途之外仍缺少的驗證。模型較接近其中某項摘要不表示整體優於既有時間外損失評估，也不據此開發新的測試集最佳模型。可直接採用的建議是不要把單局預測校準或少量連敗當成個人序列異常門檻；若要提供異常警示，須另外驗證序列覆蓋與續下機制。未使用任何新的確認性樣本。
