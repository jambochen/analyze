# 連勝連敗是否超出期望

腳本：`scripts/streaks.py`。共用 module：`scripts/runs.py`（連串的長度）、`scripts/state_adjusted.py`（`eval_rows`，Lichess 評估段的三個預報）；OGS 的評估段由 `scripts/other_games_ogs.py` 寫出。表在 `outputs/tables/streaks.csv`。規格見 `docs/methods.md`「連勝連敗是否超出期望」。本文件只寫定性結論，數值一律見對應的輸出檔。

## 問題

電競玩家常指控系統「故意製造連敗」。連輸四局之後，第五局的得分是否低於系統的期望？連勝四局之後是否高於期望？若是，需要操控才能解釋嗎？

## 資料與做法

- 各自的評估段：Lichess 2014 年下半年 arena 的 Bullet 與 Blitz，序列為同一場錦標賽；OGS 2023 年，序列為同一天（`docs/results/other-games.md`）。連串的前幾局可以落在評估段之前
- $k = 5$ 事先指定：取前四局全負（全勝）的局，算得分減期望得分的平均。Lichess 中和局打斷連串
- 一局是否納入只取決於之前的結果，期望勝率正確時殘差的平均為 0，不論玩家何時停手；直接平均殘差，不受 Miller–Sanjurjo 偏誤影響。標準誤為 dyadic sandwich
- 三個基準依序為系統的期望勝率（Lichess 為 Elo 形式，OGS 為重放的系統機率）、主基準、依狀態調整的勝率

## 結論

### 結論依賴基準：系統的期望勝率本身不校準

- 以 Lichess 的 Elo 形式為基準，Bullet 連輸四局之後反而好於期望、連勝四局之後差於期望，方向與「系統製造連敗」相反；Blitz 連輸之後與期望沒有可偵測的差異（`streaks.csv`）
- 這是校準偏差造成的：Elo 形式高估強方的優勢（`docs/results/calibration.md`），而連輸四局之後的局絕大多數是弱方、連勝之後多為強方（`streaks.csv` 的 `share_underdog_sys`），弱方的實際得分高於 Elo 的期望、強方低於。以校準過的主基準為基準，方向翻轉
- 所以「連敗是否超出期望」必須先校準期望勝率才能回答；直接拿系統的期望勝率比較，會得到方向相反的結論

### Lichess：以主基準為準，連勝連敗都多於期望

- 以主基準為準，Bullet 與 Blitz 連輸四局之後都差於期望，連勝四局之後都好於期望：結果有延續性
- Lichess 2014 年的 arena 是隨機配對，系統不依狀態挑對手，延續性不可能來自配對的操控。等級分調得不夠就足以產生這個型態（`docs/results/rating-filter.md`）：剛輸的人等級分仍偏高，期望勝率高估了他
- 改用只看上一局的依狀態調整的勝率之後，Bullet 的超額縮小到區間含 0；Blitz 縮小但仍存在。Blitz 連串的資訊不只在上一局，與比上一局更早的對局在 Blitz 有小幅增量相符（`docs/results/history-depth.md`）

### OGS：方向相反，連輸之後好於期望

- OGS 的兩個速度類別，連輸四局之後在三個基準下都好於期望；連勝四局之後的方向在速度類別與基準之間不一致
- 方向與 Lichess 相反，即連串之後有回歸。OGS 的配對混合自動配對與自選挑戰，連輸之後的對手不是隨機的，回歸可能來自連輸者改挑的對手，資料分不開

## 解讀的界線

- 兩份資料都不是電競的排隊配對，不能檢驗電競中是否有操控；能說的是：沒有操控時，連勝連敗也會多於期望勝率所示，而期望勝率是否校準會決定方向
- 前四局全負的局只占評估段的一小部分；殘差的平均以局加權，局多的玩家權重較大

## 對報告的意涵

- **回應「系統製造連敗」**：Lichess 的隨機配對中，以校準的基準為準連敗確實多於期望，但這由等級分調得不夠即可解釋，不需要操控；而以系統自己的期望勝率為準，方向甚至相反。玩家感受到的連敗是否「異常」，取決於拿什麼當期望
- **依狀態調整的勝率**：它在 Bullet 吸收了連串的超額，在 Blitz 只吸收一部分，寫成限制
