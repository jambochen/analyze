# 依狀態調整的勝率

腳本：`scripts/state_adjusted_probs.py`。共用 module：`scripts/arena_batches.py`（`player_sample_rd`）、`scripts/likelihood.py`（`fit`、`dyad_se`）。表在 `outputs/tables/state_adjusted_probs_*.csv`，圖在 `outputs/figures/state_adjusted_probs_curve.png`。規格見 `docs/methods.md`「依狀態調整的勝率」。本文件只寫定性結論，數值一律見對應的輸出檔。

## 問題

玩家排完隊、看到對手之後，系統給的期望勝率能否依玩家剛才的對局修正得更準？這是預測交付物：修正後的勝、和、負機率，與「再開一局，預期比系統的期望差多少」。預測只需要預測力，不需要因果的識別，所以變數由樣本外表現決定，不由前局效果是否顯著決定。

## 資料與做法

- 2014 年 arena 的玩家局，取同一場錦標賽內有上一局者；上半年估計，下半年評估。各速度類別、上一局結果的列數與玩家數見 `state_adjusted_probs_sample.csv`
- 每局以兩位玩家的視角各出現一次，模型是給定自身近況的條件機率，對手的近況不進模型：demo 的使用者只知道自己剛才的對局
- 模型為有序 logistic，主基準的線性預測式與和局帶寬作 offset。依序加入三步，每一步都要下半年的對數分數改善、且差值以 dyadic sandwich 估得的 95% 區間不含 0 才保留，下一步以目前保留的模型為比較基準：
  1. arena 的整體校正：線性預測式的平移與和局帶寬的縮放。主基準以全站對局估計，arena 的玩家與大廳不同
  2. 上一局結果（勝、和、負），以剛輸為參照
  3. 上一局等級分的變動 $\Delta r$：本局與上一局表頭的對局前等級分之差，不用 `RatingDiff`
- 參照模型：LightGBM、XGBoost 與 MLP，輸入相同：雙方等級分與 RD、執子顏色、主基準的線性預測式與和局帶寬、前三局結果、$\Delta r$、場內局數，全為對局前的資訊。資訊量與有序模型相同，差異只來自模型。MLP 的輸出層經與有序 logistic 相同的累積 logit 得到機率。early stopping 只用上半年的 6 月，下半年不參與任何選擇
- 評估：對數分數、ranked probability score，全部、新手、老手三組分開報告（`state_adjusted_probs_prediction.csv`）；依上一局結果分色的校準曲線（`state_adjusted_probs_curve.png`）

## 結論

### arena 的整體校正在三個速度類別都不保留

- 以上半年估得的平移與和局帶寬，套到下半年反而不如主基準本身（`state_adjusted_probs_steps.csv`）。arena 的整體偏差在半年之間不穩定，主基準不需要為 arena 另作整體調整
- 主基準的係數以含下半年的全年全站對局估計，評估時對它略為有利；各候選模型共用同一個 offset，這一點不偏袒近況項

### 上一局結果在三個速度類別都保留；$\Delta r$ 只在 Blitz 與 Classical 保留

- 加入上一局結果，三個速度類別的下半年對數分數都改善，區間不含 0
- 再加入 $\Delta r$，Blitz 與 Classical 保留，Bullet 不保留。Classical 的區間上界接近 0，樣本最小
- 係數的方向與 `docs/results/rating-filter.md` 一致：剛贏之後好於系統的期望；給定上一局結果，上一局等級分升越多下一局越好，即等級分調得不夠（`state_adjusted_probs_coef.csv`）
- 改善的幅度相對於對數分數本身很小：上一局的資訊修正的是期望得分的小幅平移，不改變勝負的大致判斷

### 「再開一局」的差距集中在剛贏之後

- 修正後與主基準的期望得分之差，以主基準的斜率換算成等級分，依速度類別、上一局結果、新手與否列在 `state_adjusted_probs_gap.csv`
- 剛贏之後修正為高於系統的期望；剛輸之後的修正小，Bullet 剛輸者即主基準本身。換算成等級分，新手的修正幅度大於老手

### 機器學習與深度學習模型不構成預測上限

- LightGBM、XGBoost 與 MLP 的下半年對數分數，在全部與老手組都不如有序模型，只在 Bullet 與 Blitz 的新手組明顯較好；Classical 的新手組沒有這個差距。三個模型分屬樹模型與神經網路，型態一致（`state_adjusted_probs_prediction.csv`）
- 老手組較差，表示它們從上半年 arena 重新學到的等級分與勝率的對應，套到下半年不如以全站對局估計的主基準穩定。資訊量相同時，彈性較大的模型沒有換到樣本外的改善；「有序模型還剩多少可改善」因此無法由它們給出上界
- 新手組的差距在三個模型都出現，不是單一模型的偶然，表示新手的勝率還有主基準與兩個近況項沒有抓到的結構。這是看過結果才發現的型態，不回頭加入有序模型的候選項；登記為事後型態，以前瞻資料檢驗

### 校準曲線

- 修正後，Bullet 剛贏與剛輸的曲線大致重合，上一局結果造成的分離被吸收
- 修正後的曲線仍隨預測的期望得分略為上升：強方的實際得分高於預測，弱方低於預測。這是 arena 上的斜率偏差，整體校正只含平移與和局帶寬，不含斜率；斜率不在事先寫定的候選項中，寫成限制
- Blitz 中預測得分最高的一格，剛輸之後的實際得分明顯低於修正後的預測

## 對後續分析的意涵

- **demo**：輸入雙方等級分、RD 與上一局結果，Blitz 與 Classical 另需上一局等級分的變動；係數取 `state_adjusted_probs_coef.csv`，即上半年估得的模型
- **前瞻驗證**：登記的檢驗量為本模型（各速度類別保留的項與上半年估得的係數）對主基準的樣本外對數分數差；新手組的彈性模型差距一併登記為事後型態

## 限制

- 樣本只限 arena 內有上一局的局；大廳對局待 API 的 `source` 取得後才能納入
- 主基準的係數含下半年的資料，見上
- 修正後仍有 arena 上的斜率偏差，見上
- 每局兩個視角的機率各自由自身的近況決定，兩者相加不必為 1；這是給定單方資訊的條件預測，不是一局的聯合模型
