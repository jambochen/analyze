# 連敗與累積偏差的固定機率參考診斷

**單局預測的用途可以保留，但不能直接拿來宣告個人序列異常。** 連敗是否多於參考，會隨時間與加權方式改變；累積偏差也沒有被近況或 RD 延伸全面吸收。這項結果支持把「單局預測」與「個人戰績警示」分開驗證，不支持心理失常、配對操控或休息效果的因果結論。

## 連敗的結論取決於誰取得相同權重

視窗等權時，較長連敗在較早測試期間高於固定機率參考；較晚期間沒有相同方向，因此不能概括為連敗普遍過多。

玩家等權時，五局連敗視窗的比例在兩種速度、兩段期間均高於相應參考。這表示以全部視窗衡量的結果，不能直接代表「每位符合觀察條件的玩家各算一份」的戰績解讀。玩家等權仍只涵蓋有足夠長歷史的玩家，並非所有平台玩家，也沒有消除續下選擇。

近況與 RD 修正不保證每個連敗長度都更接近人工參考。這不是替模型重新排名的依據；預測排名仍依既有[時間外損失評估](temporal-validation.md)。

## 累積偏差與樣本支持

Bullet 的視窗等權累積偏差較接近獨立參考的尺度；改成玩家等權後偏大，尤其較晚期間。Blitz 的十局累積偏差在兩段期間、兩種權重下均高於解析參考，近況修正會降低摘要值，但沒有使其全面回到參考尺度。只排除視窗起點自身高 RD 者也不能消除這個現象。

Blitz 的二十局視窗非常稀少，較早期間只有單一玩家的有效視窗，較晚期間也集中於少數玩家。這些極長視窗保留於輸出供查核，不能拿最大的偏差作一般玩家結論。有效視窗與玩家數均由摘要表提供，圖亦標註長視窗分母；無資料的自身高 RD 分組保留缺值。

## 能採取的做法

- 報告保留既有局前機率模型的時間外預測成果，將本診斷作為用途邊界，勿宣稱已生成或解釋完整玩家歷史。
- 玩家戰績頁同時看對手調整後的偏差、有效歷史長度與自身 RD；個人用途的評估應包含玩家等權，不能只報總體視窗平均。
- 不從本次模擬分位數製作「已失常」門檻。若要推出序列異常警示，必須另外驗證序列覆蓋，處理評分／近況回饋與續下選擇，並保留未使用資料。

## 證據界線與核對

本分析固定觀察到的對手、歷史特徵、評分與續下序列，每個實際對局抽一次勝和負，再反轉給雙方。未來局前特徵可能含先前真實賽果的資訊，因此模擬是人工條件參考，不是原過程的生成虛無模型。圖中的中央參考範圍不是信賴區間，落在範圍外不是正式拒絕獨立性的檢定；累積偏差偏小也不表示模型更好。重疊視窗的參考相依由整批對局模擬保留，未納入係數不確定性。
