# 等級分在剛輸之後是否失準

腳本：`scripts/rating_filter_error.py`。共用 module：`scripts/arena_batches.py`（`player_sample_rd`）、`scripts/likelihood.py`（`lrt_player_dyad`）。表在 `outputs/tables/rating_filter_error_*.csv`，圖在 `outputs/figures/rating_filter_error_curve.png`。規格見 `docs/methods.md`「等級分的量測誤差」。本文件只寫定性結論，數值一律見對應的輸出檔。

## 問題

Glicko 是近似的貝氏濾波器，等級分是由過去對局更新出的實力估計。估計正確時，得分減期望得分不能由對局前已知的資訊預測，包括上一局的結果與上一局等級分變動了多少。這份分析檢查這一點：剛輸或剛贏之後，系統的期望得分是否系統性地偏，偏差能否由上一局的等級分變動預測。

## 資料與做法

- 2014 年 arena 的玩家局，取同一場錦標賽內有上一局者，不限配對批次的層。各格的列數、玩家數與 RD 範圍見 `rating_filter_error_sample.csv`
- 校準迴歸：以主基準期望得分的 logit 為解釋變數、得分為反應變數的 logistic 迴歸（和局記 0.5）。完全校準時截距為 0、斜率為 1
- 三個修正的概似比檢定：RD 五等分 × 上一局結果每一格的校準檢定；加入上一局等級分的變動 $\Delta r$；$\Delta r$ 的係數是否隨 RD 五等分而不同。前者一族、後兩者一族，各以 Holm 法校正
- $\Delta r$ 是本局與上一局表頭的對局前等級分之差，不用 `RatingDiff`

## 結論

### 剛贏之後表現好於期望；剛輸之後只有高 RD 的玩家差於期望

- **剛贏之後**：Bullet 與 Blitz 的每個 RD 等分，校準截距都為正，多數格校正後拒絕完全校準（`rating_filter_error_cells.csv`）。校準曲線在整個期望得分範圍都略高於 0（`rating_filter_error_curve.png`）
- **剛輸之後**：RD 最高的五分之一，校準截距為負且校正後顯著，校準曲線在整個期望得分範圍都低於 0；其餘四個等分接近 0
- **斜率**：各格的校準斜率都接近 1，偏差是整條平移，不是預測的幅度錯
- **比較的基準**：主基準以全部對局估計，arena 有上一局的局整體略高於它，有些剛輸之後的格截距也為正。勝、和、負之間的差比各格與 0 的差更能反映上一局的影響

### 殘差能由上一局的等級分變動預測：等級分調得不夠

- 校準迴歸中加入 $\Delta r$，Bullet 與 Blitz 都拒絕係數為 0，係數為正（`rating_filter_error_tests.csv`、`rating_filter_error_coef.csv`）
- 方向的意思是：上一局等級分掉越多，下一局越差於期望；升越多，越好於期望。等級分沒有完全跟上玩家短期的狀態，系統的反應不足，不是剛輸之後把等級分降過頭
- `overreaction_share` 把係數換算成「上一局的更新中少調了多少比例」，負值即反應不足

### 隨 RD 的變化不能作為濾波誤差的證據

- 交互作用的檢定在 Bullet 與 Blitz 都拒絕「各 RD 等分的係數相同」，但型態不單調
- RD 的分布集中在下限附近：前四個五等分的 RD 範圍很窄，幾乎相同；RD 的變化幾乎全在第五等分（`rating_filter_error_sample.csv` 的 `rd_min`、`rd_max`）。前四個等分之間的差異不對應 RD 的差異，這個檢定實際上只能比較第五等分與其他玩家
- 因此「效果是否隨 RD 放大」這個區分濾波誤差與 tilt 的側面證據，在本資料上沒有足夠的 RD 變化可用。依 RD 五等分分層是事先寫定的，不因結果更換

### 解讀的界線

- $\Delta r$ 與上一局的結果幾乎綁在一起，三個檢定都分不開「等級分調得不夠」（濾波誤差）與「上一局的結果改變玩家的狀態」（tilt 或手感）
- 剛輸之後差於期望只出現在 RD 最高的五分之一，而 Lichess 的 RD 不因閒置而增加，這一組以累計局數少的新帳號為主。候選的解釋之一是新帳號的起始等級分 1500 高於多數新手的實力，等級分仍在由上往下收斂；這是事後看到的型態，須先登記，再以前瞻資料檢驗，不作結論
- 這份分析的樣本是觀察資料：上一局的結果不是隨機指派的，只有前局效果模型中的對手強弱是隨機的。結論只到「殘差能由上一局預測」，不說「上一局的結果造成下一局的表現」

## 對後續分析的意涵

- **依狀態調整的勝率**：上一局的結果與等級分變動對下一局有預測力，預測模型可以使用；預測不需要因果的識別。候選的近況項為上一局結果與 $\Delta r$，LightGBM 的滯後項也包含 $\Delta r$
- **停止規則**：殘差能由上一局預測，表示依近況停手的規則在續下者上可能有差別，與前局效果的結論同向；回測照原規格進行
- **前局效果的解讀**：Blitz 剛被分到強對手之後的前局效果，可能有一部分是等級分調得不夠，不全是 tilt；本資料分不開兩者
- **新手**：RD 最高的玩家剛輸之後的偏差，是新手處理（`docs/results/novice-period.md`）須再檢查的地方：主基準的 RD 收縮項是對稱的，吸收不了有方向的偏差

## 限制

- 樣本只限 arena 內有上一局的局；大廳對局待 API 的 `source` 取得後才能納入
- RD 五等分的切法未能提供 RD 的變化，見上
- 修正的概似比檢定以局加權；Bullet 的有效玩家數較少，接近顯著邊緣的結果須保留
