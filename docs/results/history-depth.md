# 歷史對局的長度

腳本：`scripts/markov_order.py`、`scripts/hmm_tilt.py`。共用 module：`scripts/arena_batches.py`（`player_sample_rd`）、`scripts/likelihood.py`（`fit`、`lrt_player_dyad`、`dyad_se`）、`scripts/ordinal.py`。表在 `outputs/tables/markov_order_*.csv`、`outputs/tables/hmm_tilt_*.csv`。規格見 `docs/methods.md`「歷史對局的長度」。本文件只寫定性結論，數值一律見對應的輸出檔。

## 問題

電競玩家看得到雙方的近期戰績。看到對手之後，比上一局更早的對局能否讓勝率估得更準？依狀態調整的勝率（`docs/results/state-adjusted-probs.md`）只用雙方同一場錦標賽內的上一局；這裡檢查這個限制損失多少。等級分與 RD 已是全部歷史的摘要，所以問題是：主基準與上一局之外，更早的對局還剩多少資訊。

兩種形式的「更長的歷史」：

- **前幾局的結果組合**：前 $k$ 局（$k = 1, 2, 3$）的結果組合各有自己的效果，即給定主基準的 $k$ 階 Markov
- **持續的狀態**：玩家在同一場錦標賽內處於幾個持續的狀態之一，例如失常，狀態在局與局之間轉移。這是電競玩家說的 tilt 最直接的模型，即 hidden Markov model（HMM）。它和 Glicko 不重複：Glicko 追蹤的是實力，HMM 的狀態是實力之外的短期偏離

## 資料與做法

- 2014 年 arena 的玩家局，同一場錦標賽內有上一局者，與依狀態調整的勝率相同；上半年估計，下半年評估。各速度類別的列數、玩家數與有前兩局、前三局的比例見 `markov_order_sample.csv`
- **高階 Markov**：有序 logistic，主基準的線性預測式與和局帶寬作 offset，加上前 $k$ 局結果組合的格子效果。同場不足 $k$ 局時缺的局記為「無」，三個 $k$ 的樣本相同；以階層式編碼使三者巢狀。$k$ 對 $k - 1$ 以下半年的對數分數判定，改善且 dyadic 區間不含 0 才保留；上半年另以修正的概似比檢定，三個速度類別 × 兩個增量為一族，以 Holm 法校正
- **HMM**：玩家 × 錦標賽的序列從第一局開始。$K$ 個狀態，狀態 $s$ 下的線性預測式為主基準加 $\mu_s$；轉移矩陣與每場第一局的狀態分布全體共用，上半年以 forward algorithm 做最大概似。預測為 forward filter 的一步預測，只用對局前的資訊。$K = 2$ 為主、$K = 3$ 為對照；狀態數的虛無假設在參數空間邊界上，概似比不是卡方，只看樣本外。評估的局與高階 Markov 相同，對照為主基準與一階 Markov

## 結論

### 歷史的資訊集中在上一局

- 一階 Markov 在三個速度類別都改善下半年的對數分數，即依狀態調整的勝率中「上一局結果」那一步
- 二階只在 Blitz 改善，增量小於一階；Bullet 與 Classical 不改善（`markov_order_prediction.csv`）
- 三階在三個速度類別都不改善；Classical 的格子多、樣本小，三階反而變差
- 上半年的概似比檢定在二階與三階都拒絕「更早的局沒有效果」（`markov_order_lrt.csv`）。樣本內有、樣本外不改善，表示更早的局的效果微弱或不穩定，對預測用不上，但不能據此說它不存在。三階的加權卡方權重出現負值：dyadic 的 meat 在高維時不保證半正定，三階的 $p$ 值只作參考

### 沒有持續數局的失常狀態

- $K = 2$ 的 HMM 在三個速度類別都退化成同一個結構：每場第一局幾乎確定處於較差的狀態，下一局幾乎確定離開、不再回來（`hmm_tilt_params.csv`）。它學到的是「本場第一局」，不是在正常與失常之間來回的狀態
- $K = 3$ 在 Bullet 與 Blitz 是同一個結構；Classical 多出一個平穩比例極小、平移極大的狀態，對應少數幾乎每局都贏的序列，不是一般玩家的狀態
- 評估的局都不是本場第一局，HMM 在這些局幾乎只剩一個常數平移，下半年只比主基準略好，在三個速度類別都不如一階 Markov（`hmm_tilt_prediction.csv`）
- $K = 1$ 的平移接近 0：主基準在 arena 上沒有整體偏移，與依狀態調整的勝率中 arena 整體校正不保留一致

### 本場第一局較差

- HMM 的退化解、依狀態調整的勝率中「對手在本場沒有上一局」的係數、停止規則回測中隔天第一局低於期望，三者方向一致。這是看過 2014 年結果才形成的型態，已列入前瞻驗證一併登記的事後型態（「每天第一局低於期望」），只檢驗方向

## 對後續分析的意涵

- **依狀態調整的勝率**：雙方的近況只用上一局。Blitz 的上上局有小幅增量，為了三個速度類別用同一組候選、demo 只需輸入上一局，不加入；這是預測力上的取捨，寫成限制
- **demo**：輸入雙方的上一局，不需要更早的戰績
- **停止規則**：tilt 若是持續的狀態，「連輸兩局才停」這類看多局的規則才有依據；HMM 沒有找到這樣的狀態，與回測中兩條規則都沒有用一致

## 限制

- HMM 的狀態只平移線性預測式，不改變和局帶寬；只用自身的序列，對手的狀態與上一局結果的直接效果都不在模型內
- HMM 以四組起始值估計，退化解在三個速度類別都出現，不像是局部極值，但未系統地檢查
- 歷史只限同一場錦標賽內；跨場、跨日的歷史由等級分承擔
- Blitz 的上上局未加入依狀態調整的勝率，見上
