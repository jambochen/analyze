# 從玩家角度使用分析

玩家能控制的通常是如何解讀戰績、是否接受某種對局，以及何時停下；平台端的整體配對最優不會自動變成玩家可採取的建議。各用途分開驗證，不要求它們歸入單一目標。

| 玩家問題 | 現有分析可提供 | 證據界線 |
|---|---|---|
| 連敗代表我最近打差了嗎？ | 比較連敗提示與考慮過去對手強弱的低於預期提示；檢查下一局資訊及提醒頻率 | 下一局差於預期也不識別心理狀態，更不表示休息有效 |
| 怎麼看待自己的分數與短期升降？ | 用 RD 與既有新手軌跡描述評分不確定性，避免把短期戰績當穩定實力 | 暫定等級結束不是突然變準，也沒有所有玩家通用的可信局數 |
| 這場對局是否適合想要勢均力敵的我？ | 並列分差、雙方不確定性與校準期望；平台端可加入個人分差保護 | 玩家未必能選對手；資料不能估計拒絕配對後的等待或下一個對手 |
| 連輸後休息、改天再打有幫助嗎？ | 保留既有停止規則回測與前瞻判定，明確區分描述與介入效果 | 現有證據未識別休息效果，不能建議硬撐或保證停手提升得分 |

## 近期表現提醒

新分析比較「連輸若干局」與「前幾局的實際得分低於各局局前預期」，使用固定時間外模型、相同歷史長度與訓練期固定門檻。交付是提醒覆蓋、提醒對象、後續表現及個人權重敏感度，而不是把單局輸贏當提醒正誤的真值。

設計見 [玩家提醒](player-alerts.md)，結果見 [近期表現提醒的用途與限制](results/player-alerts.md)。適合的產品形式是協助玩家檢視戰績的資訊，不是自動宣告「已失常」或「現在必須停手」。

## 首局、回來遊玩與資料不足

[首局與間隔分析](results/entry-context.md)區分本場首次出現、可觀察的開局間隔及缺少前局紀錄。模型修正沒有普遍勝出，缺歷史也不能當成休息很久。用途是幫玩家理解預測的適用範圍，不是據此給出熱身或休息長度建議。

## 既有證據的使用方式

- [新手期](results/novice-period.md)與[玩家軌跡](results/novice-clusters.md)：等級分不確定性有個人差異，應與分數一起解讀。
- [序列參考診斷](results/sequence-diagnostics.md)：總體視窗與玩家等權的連敗結論不同；單局模型的模擬分位數不能直接作個人異常門檻。
- [連勝連敗](results/streaks.md)：是否「異常」依賴比較基準，不能單靠連敗指控配對操控。
- [配對目標與個人保護](results/matching-policy.md)：降低整體平均不平衡不保證每位玩家受益；個人保護須寫出具體指標與上限。
- [停止規則回測](results/folk-stop-rules.md)與[前瞻驗證](results/prospective-validation.md)：沒有支持得分收益不等於證明休息無效，也不等於繼續打較好。
