## 欄位分群

| 前綴 | 角色 |
|---|---|
| `wx_` | 資訊截止前的實測氣象，可安全作為特徵 |
| `oracle_` | 事件時刻氣象，**用於預測即構成洩漏**，一律以前綴移除 |
| 無前綴 | 班表、機場、航空公司、壅塞、日曆 |
| `prior_leg_` | 前一航段 |
| `reported_` | 航空公司自報延誤成因，**稽核對象，不得作為解釋變數** |

`bts_pipeline` 套件未隨 Kaggle 資料發布，`select_safe_features()` 無法呼叫。
`01_ingest.py` 依資料字典的兩條規則手動重建：`oracle_` 前綴，加上一份事件後
才確定的欄位黑名單。`prior_leg_*` 不在黑名單內——發布者的 gate 已保證前一
航段實際到站早於本班 `info_cutoff_utc`。

## reported_ 的缺失是決定性的

**這是本分析最關鍵的資料事實。**缺失完全由 `arr_delay_min >= 15` 決定：
BTS 只要求延誤達 15 分鐘的航班填報成因。不是隨機缺失，也不是可插補的缺失。

三個後果：

- **樣本範圍即被界定**。稽核只能在 `arr_delay_min >= 15` 的航班上進行。
  這不是資料清理的選擇，是申報制度本身的定義域
- **不得對缺失插補**。把未達門檻的航班當成「回報 0 分鐘天氣延誤」會憑空
  製造大量的零，且這些航班本來就沒有申報義務，談不上低報
- **低報的定義隨之收斂**：在有申報義務的航班中，實測氣象惡劣但天氣延誤歸零者

即使延誤達三小時以上，歸因天氣者仍是少數。這個比例本身就值得按公司拆解。

## 為什麼零膨脹的辯護要建立在正確的量上

`arr_delay_min` 強右偏且含大量負值，最小平方不適用。但**稽核樣本限定於
門檻以上後，負值與零值問題大幅緩解**。真正要處理的是
`reported_weather_delay_min` 在稽核樣本內的零膨脹，零膨脹或兩部模型的
辯護應建立在後者上，不是前者的偏態。

## wx_ 缺失分三類，處理方式不同

| 類型 | 欄位 | 處理 |
|---|---|---|
| 測站未觀測 | 溫度、露點、風速、能見度、雲冪、雲量、降水 | 不處理，留 null |
| 不符條件不填報 | `snow_depth_cm`、`wind_gust_ms` | 填 0，另立 `_absent` 指示變數 |
| 物理上無定義 | `wind_dir_deg` | 轉正弦餘弦分量 |

「不符條件不填報」填 0 才是真實語意——無雪時雪深確實是 0。但保留 `_absent`
指示變數，使模型能分辨「測到 0」與「因為沒這個現象所以沒測」。

風向在無風或風向不定時為 null，物理上無定義。轉正弦餘弦有兩個好處：避免
0 度與 360 度被當成兩端，且無風時兩分量皆為 0，語意正確。

## 欄位增刪

- **移除** `*_obs_time_utc`：觀測時間戳記，用於驗證 gate，不是氣象條件
- **移除** `prior_leg_actual_arr_utc`：同為 gate 的驗證欄位
- **保留** `obs_missing` 與 `speci_count_1h`：前者標記測站當時無觀測，後者是
  SPECI 特殊報次數，天氣劇變時才發。兩者都帶訊號，不是審計雜訊
- `prior_leg_arr_delay_min` 與 `prior_leg_turnaround_min` 的 null 填 0：
  當日首航段沒有前一航段，null 是「不適用」而非缺失
- **新增** `is_regional`：`marketing_carrier != operating_carrier`

## 結果變數的結構性缺失

| 變數 | null 的意義 |
|---|---|
| `y1_attributed` | 無 null |
| `y2_share` | 未歸因天氣者沒有「掛多少比例」可言 |
| `y3_wx_vs_nas` | 天氣與 NAS 皆零時歸因邊界不存在 |

**Y2 與 Y3 的 null 是結構性的，不可插補，也不可當成 0。**

**一個會靜默污染統計量的陷阱**：Y3 的分母在相當多列為零（延誤既未歸因天氣
也未歸因 NAS，多半落在 carrier 或 late-aircraft）。polars 的 0/0 得到
**NaN 而非 null**，不明確排除會混進中位數等統計量而不報錯。同理 Y2 在未
歸因者身上若填 0，中位數會被拉到 0。兩者都以 `pl.when()` 明確限定定義域。

## 分層上的結構變動

- 部分航空公司只在某些年度有資料，或樣本量逐年萎縮，使公司固定效應在部分
  年度無法識別。須限定樣本量足夠的公司，或部分池化
- 年度間航空公司家數因併購而減少
- 公司 × 起點機場的格子中，相當比例樣本過少。機場效應須部分池化，不可
  各自獨立估計
