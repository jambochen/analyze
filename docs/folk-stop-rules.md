# 民間停止規則的回測

腳本：`scripts/folk_stop_rules.py`。共用 module：`scripts/arena_batches.py`（`player_sample_rd`）。表在 `outputs/tables/folk_stop_rules_*.csv`，圖在 `outputs/figures/folk_stop_rules_backtest.png`。規格見 `docs/methods.md`「停止規則」。本文件只寫定性結論，數值一律見對應的輸出檔。

## 問題

電競社群常見的經驗是「先打一把，輸了今天休息，贏了就排到輸為止」。這條規則有沒有用？期望勝率準確且結果之間沒有延續效果時，殘差是 martingale 差分，依 optional stopping theorem，任何停手的規則都不改變每局的期望殘差。規則要有用，輸棋之後的局必須差於期望，而且停下之後再來的局不能更差。

## 資料與做法

- 2014 年下半年開始的一天內的 arena 局。一天以與上一局（含大廳對局）的開局間隔超過 12 小時切分；大廳對局只用於切分，不進序列也不觸發規則。各速度類別的局數、玩家數、天數與各規則刪去的局數見 `folk_stop_rules_sample.csv`
- 兩條規則：一路下到第一次輸、連輸兩局才停。觸發的那一局保留，同一天之後的局刪去；基準為從不停
- 殘差為得分減主基準的期望得分。估計量是刪去與保留的局的平均殘差差，以局加權；另報告規則下每局的平均殘差與從不停之差（`kept_minus_never`）
- 隔天重置：有刪去局的天，其刪去的局對下一個含 arena 局的一天中的第一局
- 推論為玩家 block bootstrap；兩條規則 × Bullet、Blitz 為一族，以 Holm 法校正，Classical 只作描述

## 結論

### 兩條民間規則都沒有用

- 刪去的局平均殘差接近 0，不差於保留的局（`folk_stop_rules_backtest.csv`）。輸棋之後繼續下的局，表現與系統的期望相符
- 「一路下到第一次輸」在 Blitz 校正後拒絕「刪去與保留的局相同」，方向是刪去的局較好：照規則停反而使每局的平均殘差略低於從不停。Bullet 方向相同，校正後不顯著
- 「連輸兩局才停」在 Bullet 與 Blitz 都沒有差異
- 差距的大小相對於一局的得分很小，換算成等級分不到幾分；結論是規則無用，不是規則有害

### 停下只是把局移到隔天的第一局，而隔天的第一局更差

- 隔天第一局的平均殘差在三個速度類別都明顯為負，低於被刪去的局（`folk_stop_rules_reset.csv`）。被刪去的局延到隔天，落到的位置表現更差
- 保留的局之所以平均略低於刪去的局，有一部分來自它們包含每天的第一局：規則只刪後段的局，前段的局一律保留
- 這個「每天第一局低於期望」的型態是看過結果才發現的，不屬於事先寫定的檢驗。候選的解釋是隔了一段時間沒下的生疏，或等級分在空檔之後未反映實力的變化；本分析不區分兩者，登記為事後型態，以前瞻資料檢驗

### 新手與 Classical

- Blitz 新手的「一路下到第一次輸」差距大於老手，方向同為刪去的局較好；Bullet 新手的方向相反，但區間含 0
- Classical 的方向相反，刪去的局略差於保留的局，但樣本小、只作描述

## 解讀的界線

- 回測只刪局、不加局，估計的是「續下者採用規則」時每局的期望殘差；假設採用規則不改變玩家停下之前的行為，也不改變對手池
- 殘差以主基準計算。主基準在 arena 上仍有斜率偏差（`docs/state-adjusted-probs.md`），只要刪去與保留的局的對手強弱分布相近，這個偏差不影響兩者的差
- 隔天第一局的比較中，「隔天」取下一個含 arena 局的一天，與被刪去的局不是同一場錦標賽；兩者的差包含位置以外的差異

## 對後續分析的意涵

- **報告的建議**：依 2014 年的回測，「輸了今天休息」不改善每局的表現；停下之後隔天第一局反而更差。建議的措辭為「依系統的勝率，輸了不必停」
- **前瞻驗證**：登記的檢驗量為兩條規則在 Bullet、Blitz 的刪去減保留之差與隔天重置之差；「每天第一局低於期望」一併登記為事後型態
- **局序與表現**：pattern-mixture 曲線的第一局是否同樣低於期望，可與此對照
