# 方法規格

各方法原本解決什麼、本研究借它解決什麼，以及每個方法的模型、假設、診斷與升級規則。研究問題見 `docs/design.md`，優先級、依賴與進度見 `docs/plan.md`，文獻出處見 `docs/literature.md`。

## 借用的方法：原論文解決什麼，本研究借它解決什麼

借用時須分清兩件事：原論文用這個方法回答什麼問題、在什麼條件下成立；本研究用它回答什麼，條件是否仍成立。

### EOMM（arXiv 1702.06820）

- **原論文的問題**：「勢均力敵的配對對投入度最好」這個假設是否成立；若不成立，如何配對才能讓總流失最小
- **方法**：把等待配對的玩家視為完全圖，邊的權重是兩人配對後的流失機率之和，以 minimum weight perfect matching 求總流失最小的配對。流失機率分解為 `Pr(結果 | 雙方實力) × Pr(流失 | 自身狀態, 結果)`；後者以 logistic 迴歸估計，特徵為最近 10 局的勝和負、間隔時間與近期局數，流失定義為之後 8 小時不再下 1v1
- **關鍵假設**：給定本局結果，對手的狀態不再影響自己是否流失，即 `c(s_i, s_j, o) = c(s_i, o)`。對手只透過結果影響流失
- **理論結論**：若只有結果影響流失，且 `c(勝) + c(負) > 2c(和)`，等實力配對與 EOMM 等價；反之等實力配對反而最差。若流失只取決於自身狀態，任何配對都與隨機配對一樣
- **原論文的限制**：EA 的資料，配對由系統依實力決定，無法檢驗上述假設；策略比較只能模擬；和局機率固定為 20%，不隨分差變化
- **模擬的設定**：等待名單由真實玩家狀態的集合中抽出 P 人組成，不是真實同時在線的名單；每輪獨立，玩家的實力與狀態不隨輪更新，流失者也不離開池子；以 10,000 輪的 Welch t 檢定比較各策略。這個檢定的變異只來自模擬的抽樣，不含流失模型與實力模型的估計誤差，輪數越多越顯著；各策略留住的人數差距小。本研究的對應做法：等待名單取自真實的 arena 配對批次，流失模型以隨機配對估計並納入「結果 × 分差」，勝和負機率取自校準的有序模型，以 parametric bootstrap 傳遞兩個模型的估計誤差
- **本研究借它解決**：在 2014 年 arena 的隨機配對下直接檢驗關鍵假設：控制本局結果後，分差是否仍影響流失；以理論結論的不等式判斷等實力配對在 Lichess 上是否最好。放附錄；其離開模型是主問題續下模型的來源。配對策略的模擬不做：arena 開賽批之後多半只有兩人同時空閒，任何配法都相同
- **條件是否成立**：隨機配對使分差與玩家狀態無關，檢驗不受自選混淆。和局機率以校準後的模型取代固定值

### Heliyon 2024（Kang、Suh、Kim）

- **原論文的問題**：配對經驗與對局表現是否導致流失。假設包括：配到較弱的對手降低流失、分差的變異提高流失、勝率與連勝降低流失、連敗提高流失、遊戲階段調節上述效果
- **方法**：玩家日為單位，流失定義為之後 14 天沒有對局。雙向固定效應 logistic 迴歸（玩家、日期），回報平均半彈性；以 Hausman、Wald、概似比檢定與 BIC 選模型；依改版前後、活躍度與新舊玩家分樣本檢驗穩健性
- **原論文的限制**：觀察資料，配對由系統依分數決定，作者承認無法做隨機實驗；固定效應只處理不隨時間變的玩家差異與共同的日期衝擊，隨時間變動的混淆（如同時在線人數影響配對品質）未處理；勝率等表現變數本身是投入的結果，可能內生
- **本研究借它解決**：在 Lichess 上以同一模型分別估計大廳對局（自選對手）與 arena 對局（隨機配對），比較兩者，說明「觀察資料加固定效應」這個電競研究的常見做法與隨機配對下的估計差多少
- **條件是否成立**：大廳與 arena 的差別不只在配對是否隨機，情境也不同（錦標賽有固定時長、計分方式不同）。兩者的差距是偏誤與情境差異的合併，報告須說明，不可全歸於偏誤

### Lichess 上的連勝與贏輸效應研究（arXiv 2207.07780、2503.21713）

- **原論文的問題**：連勝連敗是否長於隨機；上一局的勝負是否影響下一局的勝率
- **原論文的限制**：前者的虛無模型打亂時間順序，忽略等級分的變化；後者只抽樣少數玩家、丟棄和局、不處理續下的選擇
- **本研究借它解決**：主問題的對照。沿用其連續對局的切分方式，改以期望得分為基準、保留和局、以 arena 的隨機對手識別上一局結果的效果、為續下建模

### crossover design 的殘留效應

- **原本的問題**：同一受試者依序接受不同處理，前一期的處理是否影響後一期的反應
- **模型**：反應 = 受試者 + period + direct effect + carryover；處理的順序隨機時，direct 與 carryover 都可識別
- **本研究借它解決**：arena 中每位玩家每局被隨機分到不同強度的對手，即多期的 crossover 實驗。前一至三局對手強弱的效果就是 carryover，也就是 tilt
- **條件是否成立**：處理（對手強弱）隨機，但期數不是固定的：下到第幾局取決於玩家是否續下，所以 period 只作描述，觀察到第 k 期的樣本經過選擇，須另外處理（見「續下的選擇模型」）

### Lee 界限與 principal stratification

- **原本的問題**：實驗中反應只在部分受試者身上觀察得到（例如就業者才有薪資），而處理影響誰被觀察到。生物統計稱為 truncation by death：死亡者沒有後續的量測
- **方法**：目標量是「不論分到哪一組都會被觀察到」的那一層（principal stratum）的效果，即 survivor average causal effect。假設處理對「是否被觀察到」的影響是單調的，把觀察比例較高的一組在反應分布的上端或下端修剪掉多出的比例，得到效果的上下界
- **本研究借它解決**：上一局對手強弱影響是否續下，下一局的表現只在續下時才有定義。界限不依賴 inverse probability weighting 的「給定控制變數，續下與表現無關」
- **條件是否成立**：單調性指「被分到較強的對手不會使任何人更願意續下」，須以資料中續下率隨對手強弱的方向支持

### optional stopping 與最適停止

- **optional stopping theorem**：martingale 在有界的停止時間上，期望值不因停止規則而改變。Doob 證明它的原始問題就是賭博系統：在公平的賭局中，沒有任何下注或停手的系統能贏。Dubins、Savage 處理不公平賭局下的最適策略
- **dynamic treatment regime**：生物統計中依病人逐期的狀態決定下一步處理的方案，其價值（照方案執行時的期望結果）可由觀察到的序列估計（Murphy 2003）。停止規則即一種方案，回測即其價值的估計
- **最適停止**：問題單調時，最適規則即 one-stage look-ahead：下一步的期望報酬為負即停（Chow、Robbins、Siegmund）
- **本研究借它解決**：電競玩家的民間規則「輸了今天休息，贏了就排到輸」即一種停手的系統。期望勝率準確且結果無延續效果時，等級分的變化是 martingale，任何停止規則都無用，這是停止規則的虛無模型。偏離它的地方由主問題與預測模型估計；one-stage look-ahead 規則即「預測的下一局殘差小於 0 即停」，直接由預測模型得出

## 各方法的統計模型

符號：一局中玩家 $i$ 的對手為 $j$，對局前等級分為 $r_i, r_j$。Elo 形式的期望得分 $E_{ij} = 1/(1 + 10^{-(r_i - r_j)/400})$；匹配品質 $q_{ij} = |E_{ij} - 0.5|$，越小越接近勢均力敵。本局結果 $o_{ij} \in \{\text{負}, \text{和}, \text{勝}\}$。

每個方法列出：反應變數、模型、主要解釋變數、估計與推論、須檢驗的假設、實作套件。

### 連續對局與流失的定義

- **做法**：不是模型，是操作定義。看同一玩家相鄰兩局開局間隔的分布（取對數），依速度類別分開；以分布的低谷或混合分布的分界決定連續對局的切分門檻，並與 arXiv 2503.21713 的 Bullet 5 分鐘、Blitz 7 分鐘比較
- **反應變數的定義**：
  - 續下：同一連續對局內是否還有下一局（二元）
  - 短期離開：之後 8 小時內是否還有對局（二元，同 EOMM）
  - 流失：之後 14 天內是否還有對局（二元，同 Heliyon 2024）
  - 錦標賽中途離開：同一場錦標賽內是否還有下一局，且距錦標賽結束仍有足夠時間
  - 回訪時間：到下一局的時間（存活時間，期末為右設限）
- **須檢驗**：結論對門檻的敏感度，至少換兩個門檻重做主要估計
- **套件**：polars

### arena 配對批次的重建

- **做法**：同一場錦標賽中開局時間相同（到秒）的對局視為同一批配對，該批的玩家即當時同時空閒者
- **須檢驗**：
  - 若配對確為隨機，批內雙方等級分應無關：以批內打亂的 permutation test 檢驗批內相關
  - 批的大小分布是否合理（多為偶數人；剩一人時延到下一批）
  - 開局時間只到秒，不同批可能同秒；以 API 的毫秒時間在抽樣的錦標賽上核對
- **套件**：polars、numpy

### 新手期的界定

- **主定義**：任一方對局前的重放 RD ≥ 110 為新手對局。110 是 Lichess 自 2015 年 6 月起標示 provisional 的門檻（`docs/literature.md`）；敏感度分析取 RD ≥ 100 與雙方累計局數皆至少 30 局
- **與代理的一致程度**：玩家局上「RD 達門檻」對「累計局數未滿 N 局」的一致率與 Cohen's kappa
- **門檻兩側的校準**：依雙方較大的 RD、雙方較少的累計局數分層，估 Elo 形式期望得分的 Cox 校準截距與斜率（fractional logit，dyadic cluster 穩健標準誤）。不用殘差大小對局數的平滑迴歸：殘差的大小同時受期望得分的分布影響，不是單純的校準量
- **左截斷的核對**：2014 年 arena 玩家的帳號建立時間（API）對照首局的左截斷旗標
- **套件**：polars、numpy

### Glicko-2 重放

- **做法**：確定性的演算法，不是估計。依 Glickman 的 Glicko-2 步驟與 Lichess 所用 `org.goochjs.glicko2` 的實作，逐局更新每位玩家各速度類別的等級分、RD 與 volatility。2014 年 7 月底以前依 `RatingFest` 所用的規則，之後依線上規則
- **驗證**：重放所得的對局前等級分與表頭 `WhiteElo`、`BlackElo` 的相符比例與差距分布；依月份、速度類別、帳號年齡分層看不相符的位置
- **須檢驗**：Python 參考實作與表頭在小樣本上逐局比對；若需加速再寫 Rust 版本，並以 Python 版本驗證一致（`CLAUDE.md` 的 Rust 條款）
- **套件**：純 Python 參考實作；必要時 Rust（pyo3）

### 期望得分的校準

- **反應變數**：白方視角的結果 $Y \in \{\text{負}, \text{和}, \text{勝}\}$，有序類別
- **模型**：
  - 描述：依 $E$ 分組的實際平均得分對 $E$（校準曲線），分速度類別、等級、新手期、對局來源（arena 或大廳）
  - 主模型：cumulative logit（proportional odds）$\text{logit}\,P(Y \le k) = \theta_k - (\beta_1 d + \beta_2 \bar r + \beta_3 d \bar r)$，$d = r_W - r_B$，$\bar r$ 為雙方平均等級分。$\theta_k$ 的間距決定和局機率；先手優勢由截距位移表示
  - 對照：Davidson 型的和局模型、arXiv 2505.24783 的和局與先手隨實力變化的配對比較模型
- **檢驗的假設**：
  - Elo 形式是否校準：把斜率固定為 Elo 隱含值 $\ln 10 / 400$ 的受限模型對自由模型，概似比檢定
  - 和局機率是否隨等級上升、先手優勢是否隨等級擴大：$\bar r$ 相關項是否為 0，概似比檢定
  - proportional odds 假設：對 partial proportional odds 模型（分差的斜率在兩個切點各自估計）的概似比檢定
- **預測評估**：以時間切分（前段估計、後段評估），比較 log loss 與 ranked probability score
- **推論**：同一玩家的多局不獨立，且同一玩家兼執白與執黑；概似比檢定以 dyadic 的 sandwich 共變異修正虛無分布（見「檢定與區間」）
- **套件**：statsmodels（`OrderedModel`）；自訂模型以 scipy 最大概似

### 期望勝率的三個基準

- **反應變數**：白方視角的勝、和、負，有序類別
- **模型**：
  - 有序 logistic：即「期望得分的校準」的主模型
  - Glicko 形式：分差乘上 $g(\sigma)$ 往 0 收縮，$g(\sigma) = 1/\sqrt{1 + 3 q^2 \sigma^2 / \pi^2}$，$q = \ln 10/400$，$\sigma = \sqrt{RD_W^2 + RD_B^2}$，即 Glickman 對一局結果的預測式。Glicko 只給期望得分，不給和局機率，所以寫成有序 logistic：線性預測式為 $\beta_4 g(\sigma) d$，切點自由估計，以表示和局帶寬與先手優勢。$\beta_4$ 自由估計而不固定為 $q$：有和局時，累積 logit 的斜率要大於 $q$ 才與期望得分的斜率相符（`docs/calibration.md`），固定為 $q$ 會把和局造成的尺度差異誤當成 Glicko 的錯。Glicko 特有的內容是收縮的形狀 $g(\sigma)$，由這個寫法保留
  - 加入 rating deviation 的有序 logistic：線性預測式為 $\beta_1 d + \beta_4 g(\sigma) d + \beta_2 \bar r + \beta_3 d \bar r$，分差的斜率隨雙方的 rating deviation 變化
- **巢狀關係**：有序 logistic 是第三者在 $\beta_4 = 0$ 的特例；Glicko 形式是第三者在 $\beta_1 = \beta_2 = \beta_3 = 0$ 的特例（實作中為分差、等級分與和局帶寬的等級分項共六個參數為 0）。三者都以第三者為共同的完整模型，各以概似比檢定比較，不需要非巢狀的檢定
- **比較**：上述概似比檢定以 dyadic 相依修正；另以 2014 年下半年的樣本外對數分數（log loss）與 ranked probability score 評估預測，差值的標準誤用 dyadic sandwich
- **為什麼用雙方合成的 RD**：lila 更新等級分時用的期望得分只含對手的 RD（`scripts/glicko.py` 的 `new_rating` 逐行移植自 lila），那是各自更新等級分用的量：白方用黑方的 RD、黑方用白方的 RD，兩方的期望得分相加不等於 1，不是一局的機率。Glickman 在《The Glicko system》中給出一局結果的預測式，以雙方 RD 的合成收縮，兩方相加為 1。本題的基準是一局的勝、和、負機率，所以用合成的 RD；Lichess 不對玩家顯示勝率，報告說明兩者的差別即可
- **RD 的尺度**：重放輸出的 RD 為 Glicko-1 的顯示尺度（`glicko_replay.parquet` 的 `white_rd`、`black_rd`）。Glicko-2 內部的 $\phi = RD/173.7178$，而 $173.7178 = 400/\ln 10 = 1/q$，兩種寫法的期望得分相同，式中直接用 RD 與 $q$
- **期望得分本身的校準**：Elo 與 Glicko 的期望得分各以 Cox 校準截距與斜率檢查，依新手與否分層，這一步直接檢驗 Glicko 原式，不經有序模型
- **主從**：主基準為加入 rating deviation 的有序 logistic，在估計 crossover 模型之前決定，寫進前瞻驗證的登記文件；另兩者作敏感度分析（`docs/expected-score-baselines.md`）
- **腳本**：`scripts/expected_score_baselines.py`；概似比檢定的修正在共用的 `scripts/likelihood.py`，其檢定水準以 `scripts/adjusted_lrt_size.py` 的模擬核對

### arena 的 crossover 模型

- **定位**：主要做法
- **樣本**：2014 年 arena 的玩家局，下一局取同一場錦標賽內者；錦標賽之後在大廳的下一局作補充。Bullet 與 Blitz 為主，Classical 只作描述
- **處理**：$h = \bar e - e$，期望匹配品質減本局的期望得分；正值為對手比依配對機制所期望的強
- **反應變數**：之後第 $k$ 局（$k = 1, 2, 3$）的勝、和、負
- **目標量**：
  - 總效果：之前的對手對下一局表現的全部影響，含經由下一局的對手與自身等級分更新的管道。是 arena 制度下的效果
  - 直接效果：固定下一局的對手後的效果，即 tilt 的對應量，類推到排隊配對時用它。下一局的對手在批內隨機，剩下的混淆只有下一局那一批的組成，以其期望匹配品質 $\bar e_{next}$ 控制
- **加權**：以玩家加權為主（每位玩家權重相同，對應一般玩家），以局加權為次。樣本的活躍度極度集中，以局加權時有效玩家數（各玩家局數占比平方和的倒數）只有數百，以玩家為群的 sandwich 類推論沒有檢定水準的保證
- **總效果的推論**：第 $k$ 局之前那一局屬於兩局以上的批時，在該批內依 lila 規則重新配對的 permutation test，sharp null 為「之前的對手完全不影響之後那一局的紀錄」。統計量為主基準 offset 的有序模型在 $h$ 係數為 0 下的一步估計（score 除以 information），以玩家加權時每列乘 $1/n_p$。對照：主基準殘差的玩家內對比
- **直接效果的模型**：有序 logistic，基準的變數自由估計（平均等級分及其平方、分差及其與平均等級分的交互作用、RD 收縮項、先手、和局帶寬的等級分項），另加自身等級分及其平方、本場已下局數的對數、$\bar e_{next}$。不用 offset：上一局會改變下一局的對手，基準的分差斜率在 arena 若有偏，偏誤會經由下一局的對手混入 carryover
- **直接效果的推論**：玩家內對比，即 crossover 設計的受試者內比較。取不含 $h$ 的直接效果模型的殘差（得分減期望得分），每位玩家算「上一局 $h > 0$ 之後」減「$h \le 0$ 之後」的平均殘差，只用兩種情況都遇過的玩家，對玩家做配對 $t$ 檢定。$h = 0$ 是設計本身的分界。標準誤另以「有共同對局的玩家對」的共變數計算，取較大者
- **直接效果的對照**：
  - 每位玩家殘差對 $h$ 的斜率，至少 10 列的玩家，等權重 $t$ 檢定：核對二分丟掉多少資訊
  - 以局加權：完整模型的係數，修正的概似比檢定（$\lambda$ 取依玩家分群與 dyadic 的較大者），玩家 bootstrap 的區間
- **不加玩家項**：$h$ 隨機指派，與玩家特徵獨立，玩家項只影響精度
- **報告的效果**：
  - 第一至三局的 carryover；以局加權時依序加入 lag 的概似比檢定
  - 輸棋本身的效果：上一局得分每少一分，下一局殘差少多少，須假設上一局的對手只經由結果影響下一局。總效果的區間由反轉隨機化檢定求得：$H_0(c)$ 下「下一局殘差減 $c$ 乘上一局得分」不隨上一局的配對而變（Imbens、Rosenbaum 2005）；直接效果的區間用 delta method。有序 logistic 的係數不可 collapse，不拿來相除
  - 劑量反應：上一局的 $h$ 分五等分，linear-by-linear 趨勢檢定；偏離線性時改以 spline 表示
  - 勝負兩邊的對稱性：$h$ 在 0 兩側各一個斜率
  - 換算成「相當於自身等級分高或低幾分」，以基準的分差斜率換算
  - 主要假設為 Bullet 與 Blitz 的第一至三局，總效果與直接效果各為一族，以 Holm 法校正
- **前提檢查**（平衡為一族、設定檢定為一族，各以 Holm 法校正，校正後仍拒絕才調整）：
  - 平衡：配對前已定的變數（自身等級分、本場已下局數、新手、RD）對 $h$ 的批內斜率，以同一套重新配對檢驗
  - 下一局的管道：上一局的 $h$ 對下一局對手等級分與 $\bar e_{next}$ 的 permutation test
  - 直接效果的模型：自身等級分的三次項、$\bar e_{next}$ 與分差的交互作用、$h$ 與 $\bar e_{next}$ 的交互作用、partial proportional odds，各以概似比檢定
- **核對**：只用純隨機規則的批（2014 年 12 人以下的批有小幅偏離隨機，`docs/random-pairing.md`）；一局一批的層另外估計，與隨機化推論分開陳述；以批次分層的 Cochran–Mantel–Haenszel 相關統計量與 Mantel–Haenszel 共同 odds ratio，反應取原始結果時含下一局的管道
- **設計的依據**：兩個目標量、不用 offset、自身等級分與本場已下局數的調整、診斷的 Holm 校正，都依冒煙測試與正式執行的診斷（平衡、下一局對手、斜率修正項、設定檢定）而定，不依效果的結果；主要做法在正式執行前寫定，不因結果更換
- **套件**：numpy、jax（`scripts/likelihood.py`）、scipy

### 續下的選擇模型

- **定位**：主要做法
- **單位**：2014 年 arena 的玩家局，排除含伺服器異常批次的錦標賽。本局屬於兩局以上的批為主（設計上的隨機），一局一批另外估計，與隨機化推論分開陳述。Bullet 與 Blitz 為主，Classical 只作描述
- **反應變數**：同一場錦標賽內是否再開一局，即 `tour_left` 取反（`docs/sessions.md`「錦標賽中途離開」）。風險集只取本局開局後經過一局的名目長度、錦標賽仍有新局開出者，避開右設限；第 $k$ 局之後的續下取「同場之後還有 $k$ 局」，風險集的時間改為 $k$ 局的名目長度
- **處理**：本局的 $h = \bar e - e$，與 crossover 模型相同
- **模型**：logistic 迴歸，各速度類別分開估計
  - 總效果：$h$，加配對前已定的變數：$\bar e$、自身等級分及其平方、本場已下局數的對數、錦標賽剩餘時間的對數、新手期（任一方重放 RD ≥ 110）、執子顏色。本局結果在配對之後，不放
  - 給定結果：另加本局結果（勝、和、負）與「結果 × $h$」。這是 controlled direct effect，只作描述與 inverse probability weighting 的權重
- **推論**：以局加權的修正概似比檢定，$\lambda$ 取依玩家分群與 dyadic 的較大者（`scripts/likelihood.py`）。升級規則的診斷是總效果模型中 $h$ 一項的檢定；Bullet 與 Blitz 的兩層為一族，以 Holm 法校正
- **單調性的檢查**：在 $\bar e$ 的五等分格內再依 $h$ 分五等分（見下節），以玩家加權估計各等分的續下率。判定規則：四個相鄰差中，方向與整體趨勢相反、且以玩家 bootstrap 的單尾檢定在 Holm 校正後拒絕者，視為單調性不成立；整體趨勢由總效果模型中 $h$ 係數的正負決定。單調性不成立的速度類別與局數只報告不假設單調性的界限
- **用途**：提供界限所需的續下率，支持單調性的方向；給定結果的模型提供 inverse probability weighting 的續下機率
- **套件**：jax（`scripts/likelihood.py`）、numpy

### 續下的選擇：界限與對照

- **問題的結構**：之後第 $k$ 局的表現只在續下 $k$ 局時才有定義，即 truncation by death。目標量是兩種對手強弱下都會續下的玩家的效果（survivor average causal effect）
- **兩組的定義**：$h$ 的分布依玩家在候選者中的位置而定：$\bar e$ 接近 0.5 的玩家 $|h|$ 較大，$\bar e$ 極端的玩家集中在 $h$ 接近 0 的中段。直接以 $h$ 的全體五等分分組，各等分的組成不同。因此先依 $\bar e$ 分五等分為格，格內再依 $h$ 分五等分；格內的分組只來自配對的隨機。比較的兩組為格內最強的五分之一（$h$ 最大）與最弱的五分之一。切點依速度類別、層與局數各自取，只用處理與配對前的變數，不看結果
- **反應變數**：之後第 $k$ 局的主基準殘差（得分減主基準的期望得分），即總效果的尺度
- **主要做法：Lee 界限**：每一格內，續下率較高的一組在反應變數分布的上端或下端修剪掉 $1 - p_{\text{低}}/p_{\text{高}}$ 的比例，得該格兩組都會續下者的平均差的上下界；各格以「該格的列數 × $p_{\text{低}}$」加權平均（Lee 2009 的共變數分格）。單調性在每一格內只要求方向一致，方向可隨格不同
- **加權**：以玩家加權為主（每列權重為該玩家在該速度類別、層與局數的樣本中列數的倒數），修剪與平均都用加權的分位數；以局加權為次
- **區間**：玩家 block bootstrap 重抽 999 次，得上下界各自的標準誤，以 Imbens、Manski（2004）的區間涵蓋效果本身；區間不含 0 才說效果在續下的選擇之下仍成立
- **對照：不假設單調性的界限**：得分有界，不需單調性也有有限的 worst-case 界限。兩組都會續下者占一組續下者的比例至少為 $(p_a + p_b - 1)/p_a$，兩組都依此比例朝不利與有利的方向修剪（Zhang、Rubin 2003），與 Lee 界限並報，顯示單調性收窄了多少
- **對照：inverse probability weighting**：權重為給定結果的續下模型所估續下機率的倒數，乘上玩家權重，在各組內正規化（穩定化）；報告最大權重與有效樣本數，最大權重不大時不截斷。須假設給定控制變數，續下與之後的表現無關。tilt 本身就是同時影響續下與表現的未觀測狀態，這個假設等於假設要研究的現象不影響續下，所以只作為「此假設下的答案」與界限對照，不作主要結論
- **有參數的敏感度分析**：續下率較高的一組中，續下者屬於「兩組都會續下」的機率設為 $\operatorname{expit}(\alpha + \gamma y)$，$y$ 為反應變數，$\alpha$ 由「平均機率等於 $p_{\text{低}}/p_{\text{高}}$」解出。$\gamma = 0$ 即只用續下者的估計，$\gamma \to \pm\infty$ 即 Lee 界限的兩端。報告效果隨 $\gamma$ 的變化，與效果的點估計變號時的 $\gamma$。Rosenbaum 的 $\Gamma$ 是指派的偏離，本題的指派已知，所以敏感度參數放在選擇上
- **多局 carryover**：$k = 1, 2, 3$。需要同場連續下更多局，選擇隨之加重；界限寬到沒有資訊時，如實報告到第幾局仍有資訊
- **套件**：numpy

### 等級分的量測誤差

- **問題**：「剛輸的人等級分剛降，較可能被低估」須假設等級分是實力的 classical 量測。Glicko 是近似的貝氏濾波器，等級分是事後平均、RD 是事後標準差；濾波器設定正確時，實力等於等級分加上與等級分獨立的誤差（Berkson 型），給定歷史時不會系統性低估，也不使斜率衰減。問題因此改寫為：濾波器在剛輸之後是否失準
- **依據**：等級分是由過去對局更新出的實力估計。估計正確時，得分減期望得分不能由對局前已知的資訊預測，包括上一局的結果與上一局等級分變動了多少。這是迴歸分析的殘差診斷：殘差與可用的共變數無關
- **樣本**：2014 年 arena 的玩家局，取同一場錦標賽內有上一局者，與 crossover 模型相同；不限配對批次的層，校準不需要隨機配對。Bullet 與 Blitz 為主，Classical 只作描述
- **變數**：期望得分取主基準的 $e$；上一局等級分的變動 $\Delta r$ 為本局與上一局表頭的對局前等級分之差（以 100 分為單位），只用對局前的資訊；RD 取自身的重放 RD，依速度類別分五等分
- **模型**：Cox（1958）的校準迴歸，即以 $\operatorname{logit}(e)$ 為解釋變數的 logistic 迴歸，反應變數為得分（和局記 0.5，binomial 變異的 quasi-likelihood）：$\operatorname{logit} E[\text{得分}] = \alpha + \beta \operatorname{logit}(e)$。完全校準時 $\alpha = 0$、$\beta = 1$
- **三個檢定**，皆為以局加權的修正概似比檢定（$\lambda$ 取依玩家分群與 dyadic 的較大者）：
  1. 分層的校準檢定：RD 五等分 × 上一局結果（勝、和、負）的每一格，檢定 $\alpha = 0, \beta = 1$。回答剛輸之後系統的期望得分是否偏了
  2. 遺漏共變數的檢定：在 $\alpha$、$\beta$ 自由的模型中加入 $\Delta r$，檢定其係數為 0。係數為負表示等級分掉越多、表現越好於期望，即降過頭；為正表示降得不夠
  3. 交互作用的檢定：$\Delta r$ 的係數是否隨 RD 五等分而不同。濾波誤差的大小隨 RD 而變，tilt 沒有理由如此；這一項是區分兩者僅有的側面證據
- **族**：第一個檢定的各格為一族，第二、三個檢定為一族，各以 Holm 法校正，限 Bullet 與 Blitz
- **描述**：校準曲線，依 $e$ 分組畫平均得分減平均 $e$，依上一局結果分色、依 RD 五等分分面
- **識別的限制**：$\Delta r$ 與上一局的結果幾乎綁在一起，上一局的結果又經由 tilt 影響下一局。三個檢定都分不開濾波誤差與 tilt，報告須說明
- **不改變 τ 重放**：以表頭校正的重放每局都把等級分重設為表頭，改變 τ 只改變 RD，產生不出另一套等級分；不校正的純重放因資料左截斷大多與表頭不符（`docs/glicko-replay.md`）
- **不另建狀態空間模型**：Glicko 本身即是狀態空間的濾波器
- **套件**：jax（`scripts/likelihood.py`）、numpy

### 依狀態調整的勝率

- **定位**：預測交付物；機器學習只用於預測，不用於「該停」的因果結論
- **樣本**：2014 年 arena 的玩家局，取同一場錦標賽內有上一局者；上半年估計，下半年評估
- **模型**：有序 logistic，主基準的線性預測式與和局帶寬作 offset。候選項事先寫定為三步：arena 的整體校正（線性預測式的平移與和局帶寬的縮放）、上一局結果（勝、和、負，以剛輸為參照）、上一局等級分的變動 $\Delta r$（見「等級分的量測誤差」）。各速度類別分開估計
- **變數的決定**：依序加入，下半年的對數分數改善、且差值以 dyadic sandwich 估得的 95% 區間不含 0 才保留，下一步以目前保留的模型為比較基準。不以 crossover 是否顯著決定：預測不需要因果的識別
- **參照模型**：LightGBM 與 XGBoost，輸入為主基準的變數加前三局結果、$\Delta r$ 與場內局數，只用對局前的資訊；early stopping 只用上半年的最後一個月。只報告它們的下半年對數分數，作為有序模型還剩多少可改善的參照
- **評估**：對數分數、ranked probability score，依新手與否分組；校準曲線
- **輸出**：修正後的勝、和、負機率；「再開一局，預期比系統的期望低多少」以修正後與主基準的期望得分之差表示
- **套件**：jax（`scripts/likelihood.py`）、lightgbm、xgboost

### 停止規則

- **虛無模型**：期望勝率準確且無 carryover 時，等級分變化是 martingale，任何停止規則的期望等級分變化相同
- **回測（主要做法）**：回測指把事先寫定的停止規則套到歷史對局序列上，估計「照規則停」時每局的期望殘差，相當於金融中把交易規則套到歷史價格上。規則只刪局、不加局，所以估計量是規則保留與刪去的局的平均殘差差，不需要模型；被刪去的局只出現在輸了還繼續下的玩家身上，他們正是採用規則後行為會改變的人，對「若大家都採用」這個量沒有續下的選擇問題。假設採用規則不改變玩家停下之前的行為，也不改變對手池
- **規則**：事先寫定四條：一路下到第一次輸（民間規則）、爆冷輸才停（上一局殘差低於事先指定的門檻）、連輸兩局才停、預測的下一局殘差小於 0 即停（one-stage look-ahead，由依狀態調整的勝率得出）；基準為從不停
- **樣本**：2014 年下半年，與預測模型的評估樣本相同；最後一條規則的模型以上半年估計，回測不用估計模型的資料
- **推論**：玩家 block bootstrap；四條規則與從不停的比較為一族，以 Holm 法校正；結論以前瞻資料驗證
- **隔天重置**：被刪去的局多半延到隔天，所以另比較被刪去的局與隔天第一局的殘差；後者不比前者好時，停下只是把虧分延後
- **判準**：每局的期望殘差，即真實的期望得分減系統的期望得分，正比於該局的期望等級分變化。不用一段連續對局的總等級分變化：停下的局多半只是延後再下，總和會使下得少的規則顯得較好
- **分組**：依速度類別與新手與否分開報告；剛輸之後的偏差集中在高 RD 的玩家（`docs/rating-filter.md`）
- **套件**：numpy

### 前瞻驗證

- **樣本**：2015 年 1 月 1 日至 4 月 19 日的 arena
- **登記文件**：動用前寫定並 commit 主基準、要檢驗的量、判定規則與最小可偵測效果
- **判定規則**：兩條皆須成立：2015 年的總效果以單尾檢定拒絕「效果不在 2014 年的方向」；2014 與 2015 年的效果以同質性檢定不拒絕，並報告兩年差值的信賴區間。檢定水準與方向在登記文件中寫定
- **檢驗的量**：Blitz 剛被分到強對手之後的總效果；依狀態調整的勝率的對數分數；停止規則回測中勝過從不停的規則
- **一併登記的事後型態**：上一局等級分變動的係數為正、剛贏之後好於期望、高 RD 剛輸之後差於期望。這三項看過 2014 年的結果才形成，只檢驗方向
- **最小可偵測效果**：依樣本量、2014 年估得的變異數與登記的檢定力計算，以等級分表示

### demo

- **形式**：React 建置的靜態網頁，放 `demo/`；模型係數由 Python 腳本輸出成 JSON
- **功能**：手動輸入雙方等級分、rating deviation 與上一局結果，輸出勝和負機率與「再開一局，預期低於平常多少」
- **模型**：依狀態調整的勝率的有序 logistic
- **限制**：不查詢帳號；不宣稱適用於今天的 Lichess

### 局序與表現：pattern-mixture

- **問題**：第幾局之後表現開始低於期望。局序後段的樣本是前面都選擇續下的人，直接比較不同局序的平均會混入選擇
- **做法**：依一段連續對局的最終長度 $L$ 分組，在每組內看第 $k$ 局（$k \le L$）的平均殘差。每組的成員固定，組成不隨局序改變，即縱貫資料中處理退出的 pattern-mixture 做法
- **定位**：描述；回答「下到第幾局之後開始低於期望」，作為停止規則的背景
- **限制**：$L$ 本身是玩家的選擇，各組之間不可直接比較；結論只到「固定長度的連續對局內，表現是否隨局序下降」
- **套件**：polars、numpy

### 可選：連勝連敗的 parametric bootstrap

- **時機**：時間不夠時不做
- **做法**：對每位玩家的實際對局序列，依主基準給出的每局勝和負機率模擬結果，重複多次，得連勝與連敗長度的虛無分布。停止的時點以續下模型（停止機率隨上一局結果與對手強弱變化）一併模擬：玩家常在輸棋後停手，保留實際停止點會低估連敗
- **檢定統計量**：長度至少 $k$ 的連勝與連敗次數，$k$ 只取一個事先指定的值
- **樣本**：arena，對手隨機，排除對手強弱造成的連勝連敗
- **Miller–Sanjurjo 偏誤**：有限序列中「連輸 k 局後的勝率」本身有偏，只以模擬的虛無分布比較
- **解讀的前提**：等級分調得不夠本身就會使連勝連敗多於期望（`docs/rating-filter.md`）；連敗多於期望不可解讀為系統製造連敗
- **套件**：numpy

## 方法的升級規則

每一步先用基礎方法，通過診斷即停，不通過才升級。規則在分析之前寫定，避免看了結果再選方法。同一環節的多個診斷視為一族，以 Holm 法校正後仍拒絕才升級。

| 環節 | 基礎方法 | 診斷 | 不通過時升級到 |
|---|---|---|---|
| 標準誤 | dyadic sandwich 與玩家 block bootstrap 並報 | 不設比值門檻：有效群數少時兩者的估計誤差都大，比值落在門檻內外多半是雜訊 | 推論一律取較保守者 |
| 修正的概似比檢定 | 加權卡方的虛無分布 | 有效玩家數落在模擬中接近名目水準的範圍，或統計量遠離顯著邊緣 | 小樣本修正的 sandwich（如 Mancl–DeRouen）重算權重 |
| 基準的比較 | 以 dyadic 相依修正的概似比檢定，三者皆巢狀於加入 rating deviation 的模型 | partial proportional odds 的概似比檢定不拒絕，或拒絕但切點間的斜率差換算成等級分可忽略 | 以 partial proportional odds 為完整模型重做 |
| 主問題的效果 | 總效果：批內 permutation test；直接效果：有序 logistic 的殘差做玩家內對比，配對 $t$ 檢定；皆以玩家加權、不加玩家項 | 平衡檢驗不拒絕；直接效果模型的設定檢定不拒絕 | 平衡不通過：只用純隨機規則的批；設定不通過：加入對應項或 spline |
| 續下的選擇 | 只用有下一局的樣本 | 續下模型中上一局對手強弱項的概似比檢定不拒絕 | Lee 界限為主，不假設單調性的界限與 inverse probability weighting 為對照 |

續下的選擇一列，實測已知診斷不會通過（輸的人較少留在場內），所以界限一定會用到。

## 模型比較與效果大小

- **概似比檢定**：檢驗事先指定的一項是否為 0。檢定的優先序見「檢定與區間」
- **非巢狀的模型**：依序
  1. 造一個包住兩者的完整模型，改為巢狀後以概似比檢定（Cox 1961 的 encompassing 原則）。三個基準即如此處理
  2. 無法巢狀時用 Vuong 檢定：兩模型逐點對數概似差的標準化，即非巢狀版本的概似比檢定；逐點差的變異數以 dyadic sandwich 估計
  3. 選預測用的模型時，以時間切分的樣本外對數分數比較，差值的標準誤用 dyadic sandwich。機器學習模型沒有可用的概似，只用這一步
- **本題的非巢狀比較**：cumulative logit 對 adjacent-categories logit 或 Davidson 模型、Elo 形式的和局分配對有序模型，用 Vuong 檢定加樣本外對數分數；對手 RD 對雙方合成的 RD，兩項同時放入模型後以概似比檢定
- **AIC**：不用。AIC 估計的是期望的樣本外對數分數，其懲罰項 $k$ 須假設模型正確且觀察值獨立，相依或設定錯誤時正確的懲罰為 $\operatorname{tr}(I^{-1}J)$；本資料樣本大，可直接以驗證樣本量測，不必靠懲罰項近似。AIC 的差值也沒有標準誤
- **BIC**：不用。相依資料下 $\log n$ 的 $n$ 沒有定義，且其一致性要求真模型在候選之中
- **效果大小**：本資料樣本大，概似比檢定對幾乎任何一項都會拒絕。每個效果都換算成「相當於讓對手幾分」並附信賴區間，顯著與否只作附帶

## 檢定與區間

- **優先序**：概似比檢定優先，做不到時用 score 檢定，最後才用 Wald 檢定。概似比檢定不受參數化影響；Wald 檢定在 logistic 類模型的效果大或層稀疏時有 Hauck–Donner 效應。score 檢定只需配適虛無模型，層化的 Cochran–Mantel–Haenszel 檢定即屬此類
- **相依資料**：同一玩家的多局與同一局的兩位玩家都使觀察值相依，一般的概似比與 score 統計量的虛無分布不再是卡方。概似比統計量不變，虛無分布改為 $\sum_j \lambda_j \chi^2_1$，$\lambda_j$ 為受檢參數那一塊 $I^{-1}V$ 的特徵值，$I$ 為負 Hessian，$V$ 為 dyadic 的 meat（Rotnitzky、Jewell 1990）；score 檢定改用 sandwich 形式的變異數（Boos 1992）。兩者都做不到時才用 sandwich 的 Wald 檢定
- **尾機率的計算**：df 為 1 時有精確解；df 較大時用 Imhof 的反轉公式，第一個週期之後以 Fourier 型積分處理振盪；尾機率小到數值積分不可靠時，改報 $P(\lambda_{\max}\chi^2_{df} > x)$，每個 $\lambda_j \le \lambda_{\max}$，所以這是嚴格的上界
- **檢定水準**：模擬核對顯示，有效玩家數（各玩家局數占比平方和的倒數）到數千時修正後的檢定接近名目水準，有效玩家數少時仍偏寬鬆，因為群數少時 sandwich 低估變異數（`docs/expected-score-baselines.md`）。真實樣本中 Bullet 的有效玩家數較少，接近顯著邊緣的結果須保留
- **信賴區間**：delta method 可用；以 permutation test 推論者，區間由反轉檢定或 bootstrap 求得

## 離散分析的做法

配對批次多半只有兩人，是大量的小層；結果分勝、和、負三類；每局是兩位玩家的配對比較。下列做法針對這三個特徵，出處見 `docs/literature.md`「檢定與離散分析」。

| 環節 | 做法 | 定位 | 理由 | 限制 |
|---|---|---|---|---|
| 主問題的總效果 | 以配對批次分層的 Cochran–Mantel–Haenszel 檢定，有序的 mean-score 版本 | 對照 | 即層內邊際固定下置換分布的大樣本近似，層多而小時仍有效 | 一局一批的層沒有層內變異，自動不貢獻 |
| 輸棋本身的效果 | 兩階段都用平均分數差，比值即 Wald 估計量；上一局對手強弱二分時即 2×2×K 的 complier average causal effect | 主要做法 | 平均分數差可 collapse，比值有定義；有序 logistic 的係數相除沒有定義 | 仍須假設上一局對手只經由結果影響下一局 |
| 大量小層的共同效果 | Mantel–Haenszel 共同 odds ratio，Robins–Breslow–Greenland 變異數 | 對照 | 層數趨於無限、每層大小固定時仍一致 | 只處理單一暴露，連續變數須分組 |
| 跨群或跨年的效果是否相同 | Breslow–Day 或 Tarone 的同質性檢定 | 主要做法 | 取代「組間差異小」的目測 | 不拒絕不等於相同，另報差異的信賴區間 |
| 模型配適 | Pearson $X^2$／自由度看過度離散；有序模型以 Lipsitz 檢定；選擇模型以 c-statistic 與 Hosmer–Lemeshow | 診斷 | 診斷有數值依據 | 大樣本下配適度檢定幾乎必拒絕，看量值不看 p 值 |
| 未觀測因素的敏感度 | Rosenbaum 的 $\Gamma$，配對批次為 matched set | 對照 | 敏感度參數有明確意義 | 本題的未觀測因素作用在續下而非指派，須改寫為選擇的版本 |
| 續下的選擇的界限 | 不假設單調性的 worst-case 界限（Zhang、Rubin 2003），加單調性即 Lee 界限，兩者並報 | 對照 | 得分有界，界限有限；假設逐層加上 | worst-case 界限通常很寬 |

## 方法的定位

每個方法屬於下列三級之一，在分析之前寫定。範圍外而不做的方法見 `docs/plan.md`「不做的分析」。

- **主要做法**：決定結論的方法
- **對照**：一律並報，顯示結論對假設或做法的依賴
- **退路**：計算或檢定做不到時才用

| 方法 | 定位 |
|---|---|
| 批內 permutation test（總效果）、有序 logistic 的殘差做玩家內對比與配對 $t$ 檢定（直接效果） | 主要做法 |

| 輸棋本身的效果（平均得分差的比值） | 主要做法，解讀時附 exclusion 的假設 |

| 不假設單調性的界限、inverse probability weighting、有參數的敏感度分析 | 對照 |

| pattern-mixture 曲線 | 描述 |

| 停止規則的回測（含 one-stage look-ahead 規則）、隔天重置 | 主要做法 |
| 連勝連敗的 parametric bootstrap | 可選 |

## 各方法的統計依據

依統計的分支檢查每個方法的理論依據，以及是否有更簡單而同樣嚴謹的做法。

### 統計推論

- **隨機化推論**：對手由已知的機制隨機指派，permutation test 的有效性只來自指派機制，不依賴模型設對。隨機化實驗中加入配對前的共變數只影響精度，不影響不偏（Freedman 2008、Lin 2013），所以 crossover 模型不加玩家項。這只對配對前的共變數成立；下一局的對手受上一局影響，屬於處理之後的變數，所以直接效果另需「給定批的組成，下一局的對手隨機」這個由設計支持的條件
- **摘要量的檢定**：同一玩家的多局以玩家為單位彙總成一個量，再對玩家做 $t$ 檢定，是重複測量最基礎的做法。玩家內的對比即 crossover 設計的受試者內比較，以玩家加權時群數就是玩家數，不受活躍度集中影響
- **檢定的優先序**：概似比、score、Wald，相依資料用修正版（見「檢定與區間」）
- **前瞻驗證**：判定規則寫成事先指定的檢定，不用「點估計落在區間內」：後者在樣本小、區間寬時反而容易通過
- **多重比較**：Holm 法；主要假設事先指定。停止規則的回測比較多條規則，「挑到最好那條」與金融回測的 data snooping 同一個問題；規則只有四條且事先寫定，以 Holm 法校正，最好的那條再以前瞻資料驗證

### 離散資料分析

- 結果分勝、和、負三類，配對批次是大量的小層，每局是兩位玩家的配對比較。對應的做法見「離散分析的做法」
- **collapsibility**：odds ratio 不可 collapse，有序 logistic 的係數相除沒有意義；需要比值時，在平均得分的尺度上計算

### 廣義線性模型

- **有序結果**：cumulative logit；proportional odds 以 partial proportional odds 的概似比檢定
- **平均得分的校準**：binomial 變異、logit 連結的 quasi-likelihood，即 Cox 校準截距與斜率
- **殘差診斷**：等級分是否失準，以校準迴歸中加入遺漏的共變數（上一局的等級分變動），以概似比檢定其係數
- **預測的變數選擇**：以時間切分的樣本外對數分數決定，不以顯著性決定

### 多變量方法

- 三類結果是多項分布，有序結構以 partial proportional odds 檢查。反應變數與解釋變數都不是高維的，不需要降維或因子模型

### 貝氏方法

- **Glicko 是被檢驗的對象**：它是近似的貝氏濾波器，等級分為事後平均；這個性質決定「剛輸之後是否低估」的論證（見「等級分的量測誤差」）
- **本研究的推論不需要先驗**：主要做法都是頻率學派的隨機化推論與概似推論

### 生物統計

- **crossover design**：每局的對手強弱是處理，前一至三局的效果即 carryover
- **dynamic treatment regime**：停止規則的價值以回測估計，即只刪局型方案的價值估計（Murphy 2003）
- **truncation by death**：下一局表現只在續下時有定義，目標量為 survivor average causal effect，以 Lee 界限求得（Zhang、Rubin 2003）
- **退出的處理**：局序與表現以 pattern-mixture 分組，取代混入選擇的局序平均
- **校準的評估**：Cox（1958）的校準截距與斜率，即臨床預測模型驗證的標準做法

### 時間序列與隨機過程

- **虛無模型**：等級分變化的 martingale 性質與 optional stopping theorem
- **最適停止**：問題單調時即 one-stage look-ahead（Chow、Robbins、Siegmund 1971），由預測模型直接得出，不需在 Markov chain 上做動態規劃
- **殘差的自相關不能當 tilt 的證據**：實力的漂移與等級分調得不夠同樣造成正相關，只有隨機指派的上一局對手能分開 tilt 與其他來源，而濾波誤差與 tilt 連隨機配對也分不開。停止規則不需要分開：不論原因，只要近況能預測下一局虧分，停下就有用
- **賭博系統**：民間的停止規則在虛無模型下無效，即 Doob 的結果；不需要博弈論，因為對手隨機分派、不對玩家的停止規則反應，這是單一決策者的序貫決策
- **狀態空間模型**：Glicko 本身即是，不另建

### 統計計算

| 計算 | 用在哪裡 |
|---|---|
| 重抽樣 | 批內 permutation test；玩家 block bootstrap；連勝連敗的 parametric bootstrap（可選） |
| 加權卡方的尾機率 | 修正概似比檢定的虛無分布，以 Imhof 或 Davies 的數值積分，或模擬 |
| 數值最佳化 | 三個基準的自訂有序模型；dyadic sandwich |
| 動態規劃 | conditional logit 的分母（已完成） |
| 確定性演算法 | Glicko-2 重放（已完成，含 Rust 版本） |

### 不採用的方法

| 方法 | 理由 | 取代為 |
|---|---|---|
| 有限混合迴歸 | 每位玩家的局數少，兩群在實務上不可分辨；群由模型定義，無法驗證 | 依速度類別與新手與否分組 |
| 狀態空間模型 | Glicko 本身即是，重建一次是重複 | 以校準迴歸的殘差診斷檢驗 Glicko |
| MLP、GRU | 「更長的歷史是否有幫助」可在 LightGBM 加入滯後項回答 | LightGBM |
| 「模擬不同強度的違反」 | 強度沒有參數化，結論取決於設定 | 有參數的敏感度分析與界限 |
| 以有序 logistic 係數相除 | odds ratio 不可 collapse | 平均得分差的比值 |
| AIC、BIC | 見「模型比較與效果大小」 | 概似比檢定、Vuong 檢定、樣本外對數分數 |
| 線性機率模型 | 擬合機率可超出 [0, 1]，變異數不齊一 | conditional logit、Mantel–Haenszel 估計量 |
