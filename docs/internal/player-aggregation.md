# 彙總到玩家再用課內方法：能否取代 sandwich

腳本：`scripts/player_aggregation.py`。表在 `outputs/tables/player_aggregation_compare.csv` 與 `player_aggregation_slope.csv`。加權偏誤的模擬在 `scripts/explore/stop_rule_weighting_null.py`。數值一律見輸出檔。

## 問題

@ch:dependence 用 sandwich 處理對局相依，超出聽眾修過的課。替代的講法是：先把每位玩家彙總成一個量，再把玩家當成獨立單位，用課內方法。這項試驗只決定報告怎麼講，不改各分析的主要做法，只用 2014 年的資料。

WLS、變數轉換與 GLS 不在考慮內。前兩者只處理變異數的大小，問題卻在同一玩家兩局的相關。GLS 要先知道 $\Sigma$，而一局同時屬於兩位玩家，$\Sigma$ 切不成區塊。

## 做法

- **以局加權**：每格的平均是玩家總和之比 $\sum_i S_{ik} / \sum_i N_{ik}$。把每位玩家的 $(S_{ik}, N_{ik})$ 當成獨立同分布，以 delta method 求變異數。它與以玩家為群的 sandwich 只差 $m/(m-1)$，是代數恆等式
- **以玩家等權**：每位玩家先算自己的差，再做一樣本 $t$ 檢定
- **比較的對象**：課內方法、以玩家為群的 sandwich、dyadic sandwich、現行做法的標準誤，以及 Holm 校正後的結論。標準誤的比值只在估計目標相同的列上解讀

## 結論

| 分析 | 能否改用 | 理由 |
|---|---|---|
| 停止規則的回測、隔天重置（以局加權） | 能 | 與現行的玩家 bootstrap 幾乎相同，結論不變 |
| 前局效果的玩家內對比 | 已是 | 現行即配對 $t$ 檢定；玩家斜率在不同局數門檻下結論穩定 |
| 續下的總效果 | 能，但要附 dyadic 核對 | 續下率差與 logistic 的結論相同；以局加權時課內方法在部分格偏寬鬆 |
| 停止規則（玩家等權） | 不能 | 有偏誤，見下 |
| 分層校準 | 不能 | 平均殘差不檢驗斜率，結論與 Cox 檢定在數格不同 |
| 基準的 $\psi$、續下係數、依狀態調整的勝率 | 不能 | 整體模型的參數，每位玩家估不出自己的一份 |

**玩家等權的偏誤**：保留的局一定以輸棋的那一局結束，而玩家的局數由結果決定，所以每位玩家的平均之差在虛無下不以 0 為中心。模擬中以局加權的差接近 0，玩家等權的差明顯為正。總和之比受 optional stopping 保護，每位玩家的比值不受保護。

## 對報告的意涵

- @ch:dependence 以「玩家是獨立單位」為主軸，sandwich 只在註腳說明兩者相同
- 修正的概似比檢定仍不可少。它的修正量來自「依玩家彙總的分數變異」，可用同一個說法介紹
- 課內方法忽略同一局兩位玩家的相關，報告保留 dyadic 核對的一句話
- 停止規則必須以局加權；玩家等權只用於局數不由結果決定的比較，例如前局效果
