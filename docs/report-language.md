# 報告用詞與方法說明

適用於 `report/` 的書面報告、投影片及講稿。簡報的句型與版面另見 `slides.md`；個別術語的定義見根目錄 `GLOSSARY.md` 與 `docs/glossary.md`。

## 讀者與首次說明

讀者是統計研究所師生。數理統計、迴歸與 likelihood 可作為起點；不要因方法出現在引用論文中，就假設讀者已學過。離散資料方法、PPML、fractional logit、separation、FDR、名次信賴集合與 plasmode 首次出現時，先用已知概念說明它解決什麼問題，再給名稱和公式。模擬可從 MC 的「重複生成資料並重估」說起。

航空欄位或縮寫首次出現時說明其申報意義。`weather`、NAS、`late-aircraft` 等欄位的定義以 `GLOSSARY.md` 為準；申報分類不等於已查證的真實成因。

中文譯名若生硬或不足以讓讀者理解，保留英文原名，接著用白話說明用途。譯名是否存在，不能當成讀者已懂該方法的證據。不要為本題另造方法名。

## 每個方法的講述順序

簡報以既有論文的流程為主線：界定可比對象、量偏離、排序與標記、驗證。先完整介紹作為出發點的論文，再依這四步逐一替換。

1. 先說論文在這一步怎麼做，包含原文的資料與問題。
2. 指出本題資料的哪項特徵使該做法不能照搬，並展示相應的圖，例如零分鐘、固定總分鐘、同場同月的公司重疊。
3. 再介紹替換的候選方法、它出自哪篇論文、公式中的量與預計輸出。同一步有多個候選時並列比較，說明各自對資料的假設。講稿可以補充投影片省略的推導。

每個方法標明定位，分三級：主要做法、檢查、備選。不要把所有方法都稱為「候選」，聽者會分不出主張；方法仍可更換一事在開場與結尾說明即可。每頁標明所在步驟，步驟以名稱指稱，不編號。

術語、符號與縮寫在首次出現的那一頁定義；同一個量全篇只用一個名稱與一個符號。同一步超過五頁時，加次一層的路標，並以同一個數字例子貫穿各頁的公式。

文獻引用須對應一項具體做法；「提供依據」「借用思路」後面要寫出所依據或借用的是哪一步。

## 用詞檢查

- 寫出關係的兩端及其作用。若使用「連結」「支持」「可比」等詞，讀者應能看出哪些公司、資料或參數透過什麼條件產生關係。例如一月在 X 機場有甲、丙，二月在 Y 機場有丙、乙；兩組分別提供甲丙和丙乙的比較資訊，模型可能據此估計甲乙的差異。仍須檢查公司效果能否辨識。
- 保留會改變統計解讀的區別，例如零分鐘與無填報義務的空值、申報差異與不實申報、公司排序與 BH 證據標記。刪除只重述前句的對比或結語。
- 用日常的詞。「同儕」這類書面而生硬的詞改成「其他公司」「比較對象」；白話說得清楚時不用較文的說法。
- 先用一句話說明術語的用途，再檢查是否仍需要該術語。投影片正文看不懂時，不能只把定義移到講者註解。

改動術語或說明順序後，核對 `methods.typ`、`methods_keypoints.md`、`methods_doc.typ` 及詞彙表的相應位置。執行 `make report-pdfs` 並檢視改動頁面；編譯通過只能確認排版，不能代替用詞審閱。
