# 玩家近期表現提醒的評估

## 玩家能使用的問題

連敗是否足以判斷自己最近低於預期？提醒應只看輸贏，還是先考慮過去對手強弱？此分析評估提醒的頻率與下一局預測資訊，不估計休息、熱身或繼續玩的效果。

使用 Lichess 2014 年 arena 的 Bullet 與 Blitz，沿既有兩個向前時間切分，固定讀取訓練期係數；不使用 2015 年前瞻驗證，也不重新選預測模型。新問題在已使用資料上提出，屬探索。

## 規則與資料可得性

以同一玩家、同一場錦標賽的前五局形成共同評估樣本。沒有足夠歷史者不產生本分析的提醒。規則均在下一局對手與結果尚未知道時可計算：

- 過去至少連輸三局。
- 過去至少連輸四局。
- 前五局累積實際得分減去各局局前 RD 基準期望，除以各局預測得分變異總和的平方根，低於固定負門檻。
- 同一標準化偏差，但門檻由訓練期分位數決定，使訓練期提醒率與三連敗相近；測試段不再調整。

標準化量只是提醒分數。局間可能相依、模型亦有誤差，不把它當常態檢定量或異常的 p 值。固定門檻取負 1.645 作探索性參照；沒有用測試結果選它。和局記為半分並打斷連敗。

各切分的模型在切分起點已可取得，因此可重新評估此前已發生的歷史局。提醒完全取前局資訊；本局對手只用於事後核對提醒後的結果，不能回流提醒。回放不包含玩家採用提醒後的行為改變。

## 判準

同時報告提醒占符合歷史條件的玩家局比例、收到提醒的玩家比例、玩家提醒率分布，以及提醒後下一局的勝負、得分與兩個模型的期望。以實際得分減去當局 RD 基準／近況模型期望的殘差，區分對手較強與在對手條件下仍低於預期。

提醒組與未提醒組的平均殘差差，用玩家與對手相依修正的標準誤呈現條件於固定模型的描述性區間；不是對提醒介入效果的估計，也未包含模型訓練不確定性。多組區間不當作獨立確認性檢定。

加入每位玩家等權重的敏感度比較、提醒是否集中於少數玩家，以及各曆月的描述，避免少數高頻玩家主導整段結果。等玩家權重分別在提醒與未提醒組內給每位有觀察值者相同總權重，不是同一組玩家的介入對照。

按玩家自身 RD 分組；高 RD 是等級分不確定性，未必等於新帳號。另將三連敗與等頻率偏差提醒分成兩者皆有、只有連敗、只有偏差、兩者皆無，觀察兩種提醒是否在挑不同情境。

## 界線

樣本只包含同場至少已下足夠局、且繼續開下一局的人，不代表所有連敗或收到提醒的玩家。不能將後續勝負當成提醒是否誤報的真值：單局輸贏有隨機性，真正的狀態亦未觀察。

若提醒後有額外負殘差，只支持值得在戰績頁呈現的預測資訊；不能推出休息可改善、停手能保分、繼續較好，或玩家已進入可識別的心理狀態。時間間隔是開局間隔，也不能直接當休息長度。
