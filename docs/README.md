# 文件索引

要回答什麼問題，讀哪一份。一次任務通常只需讀一份。

| 文件 | 回答 |
|---|---|
| `design.md` | 研究問題是什麼？交付物？受益者？哪些方向不做？ |
| `data.md` | 資料長什麼樣？樣本怎麼界定？缺失怎麼處理？ |
| `decisions.md` | 為什麼用這個方法？哪些做法已證實不可行？ |
| `findings.md` | 目前算出什麼結論？下一步要做什麼？ |
| `methods.md` | 這一步可以用什麼方法？下一步該做哪個方向？課程筆記裡有什麼？ |
| `glossary.md` | 這個概念用哪個術語？哪些詞不用？ |
| `report-language.md` | 報告與簡報如何介紹新術語、資料特徵及方法文獻？ |
| `literature.md` | 這個方法引哪篇文獻？哪些出處已查證？ |
| `slides.md` | 簡報上的文字怎麼寫？標題、條列、文言成分、標點的體例。 |

查文獻時先看本機 `ref/` 是否已有全文；已核對副本的對應關係、閱讀範圍與
適用限制記在 `literature.md`。`ref/` 存放本機 PDF 與 TeX 原始檔，其他環境未必有這些檔案。

報告與簡報以 `make report-pdfs` 產生；命令會先檢查統計圖的圖說語言，
再以專案根目錄編譯四份 Typst 文件。修改圖表或排版後，應檢視 PDF 中受影響的頁面，
確認文字、圖例與圖說沒有重疊或裁切。

寫作規範見 `CLAUDE.md`「文件規範」：不寫數值、只寫現況、不寫階段編號。
所有數值在 `outputs/tables/`、`outputs/figures/` 與腳本輸出。
