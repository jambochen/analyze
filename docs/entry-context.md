# 首局、開局間隔與預測適用範圍

## 問題

共同預測基礎需涵蓋本場首局及回來遊玩的情境，才能同時服務平台配對與玩家戰績解讀。檢查本場首局、前後開局間隔是否在既有近況模型之外提供時間外資訊；再比較限制模型適用範圍的覆蓋代價。

只使用 Lichess 2014 年 Bullet、Blitz；依既有 Jul–Sep 與 Oct–Dec 切分，訓練在各測試段以前。已看過的資料作探索，不更改或重用 2015 年前瞻驗證。每局取白方一列估計與評估，對手與玩家相依另作修正。

## 共同基礎與候選

保留本場沒有前局的玩家。固定套用既有 RD 基準及近況模型的完整係數；僅一方有歷史時按該方視角修正，雙方均無歷史則回退基準。本場首局是同一錦標賽中該玩家第一次出現，不等於整天首次遊玩。

候選一律事先列出，不依測試段挑選：

- 固定既有近況模型，作參考。
- 只重新校準：調整優勢項的截距與斜率，以及和局帶寬。
- 重新校準加雙方本場首局指標之差。
- 重新校準加雙方開局間隔類別之差。
- 重新校準加上述兩類資訊。

間隔分為不超過五分鐘、五至三十分鐘、三十分鐘至六小時、六至二十四小時、超過二十四小時，以及缺少前局紀錄。以最短區間為參考，區分指標取自身減對手，保持對調雙方時的方向一致。缺歷史不填成長時間未玩。

開局間隔包含上一局的遊玩時間，不是真實休息長度。特徵改善預測也不能解讀為休息造成進步或退步。重新校準對照用來避免把一般校準修正全部歸因於新增情境資訊。

## 評估

比較相同測試對局的對數損失、期望得分誤差及共同預測分箱的偏差。首局、非首局、長間隔、間隔可觀察及缺少前局紀錄情境分開報告。缺少前局紀錄不等於新帳號，也不等於長時間休息。以局加權與等玩家權重並列；後者讓每位出現的玩家對其參與對局的總權重相同。區間使用玩家與對手相依修正，條件於已估計的模型，不包含重抽訓練及模型選擇。

同一估計量中，先固定保留集合再比較模型，不以低 RD 子群損失較低直接宣稱篩選有用。限制規則包括雙方 RD 均低於既有門檻、局前特徵落在訓練支持範圍，以及兩者同時成立。支持範圍用訓練期平均等級分的第一至第九十九百分位及絕對分差的第九十九百分位固定；測試期不重訂門檻。

覆蓋率之外，報告首局、高 RD 與缺少前局紀錄者各自被保留多少。這些篩選不是已校準的信心區間，也不構成自動拒絕服務的部署規則。若剔除大量玩家卻沒有穩定改善校準或模型增量，應如實呈現。

## 核對

原始資料不改動；當局結果僅為反應變數，當局 RatingDiff 不作特徵。首局與間隔均在開局前已知。配適須通過一階條件、機率合法性與樣本時間界線；分組、覆蓋率及兩種權重互相核對。
